# Сплошной иней между ледяными пятнами

Обновлён `/Game/Gameplay/Cold/Frost/M_TongueFrost`. Резервная копия: `/Game/Gameplay/Cold/Frost/M_TongueFrost_BeforeFrostFill`.

В холодной области открытые промежутки между гладкими ледяными пятнами заполнены светлым матовым инеем. Кристаллическая маска теперь также меняет цвет этого сплошного слоя, сохраняя видимые веточки. Различия блеска, оттенка и небольшого рельефа ледяных участков сохранены. Схема по-прежнему использует два Substrate Slab BSDF.

Покрытие начинается сразу за действительным безопасным радиусом: прежний дополнительный отступ убран. Мягкий переход сокращён до 45 см; его ширина немного меняется по поверхности. Внутри обоих тёплых кругов язык остаётся открытым. При появлении зимы сначала проявляются кристаллы, затем заполняется фоновый слой; при нулевом IceAmount покрытие скрыто.

Актуальные настройки:

- **Frost Fill** — заполнение промежутков; 1 даёт сплошное покрытие при полном холоде.
- **Warm Fade Width** — базовая ширина мягкого перехода, 45 см.
- **Warm Edge Variation** — небольшая разница ширины перехода, 12 см.
- Настройки ледяных пятен и их рельефа остались прежними.

Материал сохранён и скомпилирован без ошибок. Короткий PIE-предпросмотр проверил частичное и полное проявление, смену тёплых кругов, сохранение UV/геометрии языка и удаление покрытия. `PreviewVerification.json`: passed=true. Финальный вид: `TongueFrost_full.png`; два тёплых круга: `TongueFrost_two_zones.png`.

Перед сохранением завершён режим Play, поскольку EditorAssetLibrary не поддерживает операции с ассетами во время PIE. После проверки PIE завершён. C++, материал персонажа, игровая область безопасности и основная текстура языка не менялись. Сетевой сеанс, cook и package не запускались.
