# Иней персонажа

Маска: `/Game/Gameplay/Cold/Frost/T_PlayerFrostMask`.
Рабочее покрытие: `/Game/Gameplay/Cold/M_PlayerIceCoating`.

Иней появляется на отдельном покрытии персонажа поверх его обычных материалов. Существующая механика холодной зоны увеличивает реплицируемый `IceAmount`, а тёплая зона уменьшает его. По мере охлаждения сначала появляются яркие кристаллы маски, затем более тёмные веточки. При нулевом замерзании покрытие полностью скрыто. Чёрные промежутки маски остаются прозрачными.

Настройки в группе **Player Freeze**:

- `Frost Mask Texture`: текстура кристаллов.
- `Frost Tiling`: масштаб узора; меньшее значение делает кристаллы крупнее. По умолчанию 1.
- `Frost Softness`: плавность проявления кристаллов. По умолчанию 0.10.
- `Frost Strength`: белый матовый иней поверх исходного льда. По умолчанию 0.85; при 0 используются исходные цвет и шероховатость льда.
- `Frost Tint`: оттенок кристаллов.
- `IceAmount`: существующая игровая шкала 0–1, устанавливается автоматически.
- `IceThickness`: существующая толщина ледяного покрытия.

Маска подключена через DitherTemporalAA к Opacity Mask. Поверх исходного графа Substrate добавлены регулируемые цвет и шероховатость белого инея, чтобы веточки были видны на синем льду. Нормали исходного льда сохранены. Сам `M_Ice` не изменён. Резервная копия прежнего покрытия: `/Game/Gameplay/Cold/Frost/M_PlayerIceCoating_BeforeFrostMask`.

PNG-источник: `ArtSource/Cold/Frost/T_PlayerFrostMask.png`.
Текстура создана встроенным инструментом image_gen. Точный запрос сохранён рядом в `GenerationPrompt.txt`. Текстура импортирована с sRGB=false, Grayscale compression и Wrap.

Проверка авторинга: материал скомпилирован без ошибок, в PIE проверены два уровня заморозки и исчезновение покрытия в тёплой зоне. Сборка, cook и package не запускались.
