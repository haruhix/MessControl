# M_ArenaTooth assignment

The user's exact material is assigned to every current arena tooth component,
the 26 derived tooth mesh defaults and the gameplay tooth profile.

- `Assignment.json`: before/after assignments and protected asset hashes.
- `SoloCheck.json`: exact material bindings checked on actual spawned teeth.
- `FinalAudit.json`: saved component/mesh/profile and preservation checks.
- `DiskBefore`: recovery copies of affected mesh, profile and map packages.

The material graph, gum edge masks, tongue and existing unsaved edits are
preserved. See `Docs/ArenaToothMaterial_20261017.md`.
