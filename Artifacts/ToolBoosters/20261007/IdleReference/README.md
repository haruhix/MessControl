# Idle-хват по образцу

Исходник — четыре позы SM_MeshaBrush, SM_Chainsaw, SM_Buffer и SM_Watergun с четырьмя копиями персонажа в открытой сцене D:/PROJECT/GAME/TEETH CONTROL/teeth/Character.blend. Blender-сцена не изменена. Матрицы объектов и костей, размеры и точки хвата записаны в BlenderReference.json.

При переносе координаты Blender переведены в систему персонажа Unreal, метры — в сантиметры, а высота центра капсулы учтена через StandingMeshTransform. Повороты кистей перенесены относительно позы покоя исходного и импортированного скелетов. Привязка меша рассчитана из правой кисти; левая точка и поворот заданы относительно меша. Calibration.json содержит полученные параметры DA_Equipment.

У каждого улучшенного инструмента есть свой IdlePose. Процедурная анимация вычисляет положение правой кисти из этой позы и текущей привязки меша; левую кисть ведёт точка SupportGrip/SupportRotation либо сокет GripLeft. Бленд возврата в idle плавный. Рабочие позы пилы и watergun учитывают полный поворот привязки инструмента.

Проверки: Presentation.json — размеры, положение и оба хвата всех четырёх инструментов; Working.json — работа пилы над полом, Pain и Effort; Network.json — серверное и клиентское отображение плюс выдача через F3; BufferVerification.json — 32 из 39 камней удалены полностью за одно нажатие. Все 13 проверок ToolBoosters и Inventory прошли в Tests/index.json. Сборка MessControlEditor успешна. Снимки сделаны в игре; общий Idle_AllTools.png использует временные копии персонажа, удалённые после съёмки.
