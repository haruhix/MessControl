# Настройка налёта через Material Instance

Рабочий инстанс: `/Game/Gameplay/Care/MI_ArenaToothGrime`.
Родительский граф: `/Game/Gameplay/Care/M_ArenaToothRelief`.

Каждый игровой зуб создаёт свой динамический материал от сохранённого инстанса.
Параметры внешнего вида наследуются из инстанса, а индивидуальная маска чистки
и состояние налёта передаются в динамический материал самим зубом.

## Основные настройки

| Группа | Параметр | Назначение |
|---|---|---|
| 01 Pattern | GrimePigmentSize | Размер рисунка в см; исходное значение 420. |
| 01 Pattern | GrimePatternSeed | Новый вариант случайного рисунка с сохранением различий между зубами. |
| 01 Pattern | GrimeWarpStrength | Деформация рисунка; исходное значение 0,10. |
| 01 Pattern | GrimePigment | Текстура налёта. |
| 02 Coating | GrimeOpacity | Общая прозрачность. |
| 02 Coating | GrimeEdgeSoftness | Мягкость перехода к эмали. |
| 02 Coating | GrimeEdgeErosion | Неровность края. |
| 02 Coating | GrimeWashOpacity | Плотность светлых разводов. |
| 03 Surface | GrimeTint | Цветовой множитель; белый сохраняет исходные цвета. |
| 03 Surface | GrimeRoughness | Шероховатость. |

`04 Micro Surface` содержит прежние настройки микрорельефа.
`90 Runtime Automatic` содержит значения, которыми управляет игра.
Исходные настройки внешнего вида сохранены.

Проверки и фактическая длительность чистки записываются в `Solo/SoloCheck.json`,
проверка наследования параметров — в `RuntimeInheritance.json`, общий результат
и восстановление временных настроек — в `FinalAudit.json`.
