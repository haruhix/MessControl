# Поддержка геймпада

Добавлены камера на правом стике с независимой от FPS скоростью, мёртвая зона обоих стиков, основное действие RT, усилитель B, меню Start и таблица игроков View. Меню поддерживает явное переключение фокуса, выбор A и возврат B; выбор перков — стик / D-pad, A и переброс Y. Эмоции доступны из меню паузы. Подсказки игровых действий и обучения переключаются по устройству ввода.

Раскладка: `Docs/Gamepad.md`. Сборка: `D:\PROJECT\GAME\WaifuTD\MessControl\Saved\Builds\Win64_Gamepad_20261016_232027`.

Проверки: меню; игровые действия при 30 и 120 FPS в редакторском игровом процессе и в упакованном EXE; запуск карты и лаунчера. Все прошли. Программные события проходят через Enhanced Input и Slate; физический контроллер и сетевое подключение не проверялись. Временные настройки компилятора восстановлены побайтово.
