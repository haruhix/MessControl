# Покрытие инеем при движении

Исправлено рассогласование формы персонажа и ледяного покрытия. Кости и морфы уже передавались через Leader Pose, но шейдерные деформации основного материала отсутствовали в материале льда.

В `/Game/Gameplay/Cold/M_PlayerIceCoating` добавлена та же ветка World Position Offset, что используется в `/Game/Art/Materials/M_TeethGameplay`: сжатие/растяжение через `BodyStretch` и сколы через `Damage`/`DamageChipDepth`. Поверх этого смещения сохранён прежний отступ ледяного слоя.

`AMCIceEvent::RefreshIceCoatings` получает текущие значения из каждого материала исходной модели. У слотов отдельные динамические материалы покрытия, потому что тело и пояс могут иметь разные параметры деформации. Зависимость тика от персонажа позволяет читать значения после обновления его анимации; при удалении покрытия зависимость снимается.

В открытом редакторе успешно выполнен Live Coding. Проверка PIE прошла при ходьбе и прыжке: скорость превышала 300 см/с, BodyStretch менялся от -0.020 до 0.173, морф Stretch достиг 0.617. Значения деформации во всех слотах покрытия точно совпали с исходными материалами. Оттаивание удалило покрытие; исходные материалы сохранены. Подробности: `MotionVerification.json`.

Материал скомпилирован без ошибок. Сборка, cook и package не запускались. Временные настройки Live Coding восстановлены.

Резервная копия покрытия: `/Game/Gameplay/Cold/Frost/M_PlayerIceCoating_BeforeMotionFix`.
