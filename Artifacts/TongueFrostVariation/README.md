# Разнообразное покрытие льда на языке

Позднее холодные промежутки заполнены сплошным инеем, а ширина перехода уменьшена для читаемости круга. Актуальный вариант описан в `Artifacts/TongueFrostFill/README.md`; ниже сохранено описание предыдущего варианта.

Обновлён материал `/Game/Gameplay/Cold/Frost/M_TongueFrost`.
Предыдущее состояние сохранено в `/Game/Gameplay/Cold/Frost/M_TongueFrost_BeforePatchVariation`.

Покрытие состоит из отдельных гладких голубых ледяных пятен, шероховатых белых скоплений инея и открытых участков языка. Два настоящих Substrate Slab BSDF соединены через Horizontal Blend. У оператора включено Parameter Blending. Рельеф использует исходную normal-текстуру `M_Ice` с более мелким масштабом и добавляет до 1,6 см высоты отдельным участкам.

Органическое поле в исходных UV языка независимо меняет крупные пятна льда, скопления кристаллов, оттенок и шероховатость. У тёплой зоны оно меняет начало и ширину градиента по поверхности. Переход начинается снаружи безопасного радиуса; внутри обоих игровых тёплых кругов покрытие скрыто. Поле не использует время или мировое положение для узора, поэтому не скользит по языку при движении.

Основные параметры:

- **Ice Patch Coverage** — количество гладких ледяных пятен, по умолчанию 0,52.
- **Ice Patch Scale** — размер пятен: меньшее значение увеличивает их. По умолчанию 24.
- **Ice Patch Softness** — мягкость края отдельного пятна, 0,075.
- **Frost Clump Coverage** — количество скоплений белого инея, 0,67.
- **Warm Fade Width** — базовая ширина оттаивания, 120 см.
- **Warm Edge Variation** — неравномерность края оттаивания, 65 см. При 0 градиент снова равномерный.
- **Ice Detail Tiling** — масштаб мелкого рельефа, 10.
- **Ice Roughness**, **Frost Roughness**, **Ice Plate Tint**, **Frost Tint** — блеск и цвет разных участков.
- **IceThickness** — небольшой рельеф ледяных пятен, 1,6 см.
- **Pattern Offset** — сдвиг органического узора.

Существующие `IceAmount` и параметры обоих тёплых кругов задаются зимним событием. Кристаллы используют прежнюю текстуру `T_PlayerFrostMask`. Opacity Mask по-прежнему подключён через DitherTemporalAA с отключённой константой UseConstant. Новая схема Front Material не использует прежнюю функцию SMF_UE4Legacy; её узлы сохранены как исходная ветка в графе, резервная копия материала содержит исходное подключение.

Материал сохранён и скомпилирован без ошибок. В коротком PIE-предпросмотре проверены частичная/полная заморозка, смена тёплых кругов, сохранение геометрии/UV языка и удаление покрытия после завершения события.
