# Иней на языке и мягкий край тёплой зоны

Позднее материал дополнен отдельными ледяными пятнами, двумя Substrate Slab и неравномерным градиентом оттаивания. Затем промежутки между льдом заполнены инеем для читаемости круга. Актуальные настройки и скриншоты находятся в `Artifacts/TongueFrostFill/README.md`; ниже описан первоначальный вариант.

Материал: `/Game/Gameplay/Cold/Frost/M_TongueFrost`.
Маска кристаллов: `/Game/Gameplay/Cold/Frost/T_PlayerFrostMask` — та же текстура, что у персонажа.

Зимнее событие автоматически назначает материал на своё покрытие `FrozenTongue`. `IceAmount` растёт с прибытием холода. Кристаллы проявляются постепенно, а тёмные промежутки маски остаются прозрачными.

Внутри безопасного круга инея нет. Снаружи его границы покрытие плавно нарастает по `smoothstep` на протяжении **120 см**. Переход рассчитывается для каждого пикселя до `DitherTemporalAA`, поэтому треугольные вырезы больше не нужны. При смене кругов учитываются обе тёплые зоны. Игровой безопасный радиус остаётся прежним.

Настройки материала:

- **Warm Fade Width**: ширина перехода в сантиметрах. По умолчанию 120; большее значение делает край мягче.
- **Frost Tiling**: повторение узора в UV языка. По умолчанию 6; меньшее значение увеличивает кристаллы.
- **Frost Softness**, **Frost Strength**, **Frost Tint**: плавность проявления, яркость и оттенок кристаллов.
- **IceAmount**, **Warm Center**, **Warm Radius**, **Warm Enabled**, **Next Warm Center**, **Next Warm Radius**, **Next Warm Enabled**: автоматически задаются событием.

Покрытие использует текущие вершины, нормали, касательные и исходные UV языка. Оно обновляется после деформации языка, с отступом 2,5 см по нормали. Существующий буфер обновляется без повторного создания секции. Исходный материал языка сохраняется, покрытие удаляется после завершения события.

Авторинг и проверка:

- Материал сохранён и скомпилирован без ошибок; у подключённого Opacity Mask отключена константа `UseConstant`.
- Изменение C++ применено через Live Coding. Конфигурация сборки восстановлена.
- В PIE проверены частичное и полное проявление, две тёплые зоны и удаление покрытия. UV и индексы совпадают с языком; проверенные вершины имеют ожидаемый отступ по нормали.
- Скриншоты: `TongueFrost_low.png`, `TongueFrost_full.png`, `TongueFrost_two_zones.png`. Отчёт: `PreviewVerification.json`.
- Сетевой сеанс, cook и package в этой задаче не запускались.

Состояние C++ перед изменением сохранено в `MCIceEvent.Before.cpp`. Материал персонажа и исходный `M_Ice` этой задачей не изменены.
