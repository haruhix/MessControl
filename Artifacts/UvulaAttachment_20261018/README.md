# Верхнее крепление интерактивного язычка

[Посмотреть видео](UvulaAttachment.mp4) · [Манифест](PreviewManifest.json) · [Изменение карты](Changes.json)

В игре используется один видимый `SM_InteractiveUvula` — существующая рабочая
копия `SM_MiniTong`. Старое декоративное представление не используется.
Изменена только translation параметра `AuthoredUvulaRestTransform`: подъём
на 500 см в мировых координатах. Нейтральный центр теперь Z=1100,23 см,
верхнее крепление Z=1457,73 см. Корень глотки, AuthoredMouth, отверстие,
фиксированный morph 0,75 и три исходных mesh-пакета сохранены.

Короткий настоящий solo PIE-сценарий длится около 5,5 с: idle → выстрелы
watergun обычным удержанием ЛКМ → восстановление. Принято 55 исходных игровых
кадров; их временной диапазон 5,40 с, итоговый MP4 5,57 с. Нормальный первый
перк выбран через обычный UI, затем только посторонний планировщик дня
временно остановлен. Обзорная камера передаёт существующий входной RPC
`ServerCommitSprayView`; попадание, tickle и анимация остаются нативными.

Проверены единственный видимый новый язычок, отсутствие видимого старого,
верхнее крепление, движение кончика и неизменность корня/AuthoredMouth/morph.
Ведущий и независимый агент приняли настоящий визуал idle, реакции и
восстановления. Крупный план не показывает отверстие целиком; сохранение
его расположения проверено отдельно по transform и редакторской квитанции.
Еда, броски, боссы, волны, сетевое поведение и готовый Windows-пакет этим
роликом не проверяются.

MP4 скопирован без перекодирования, SHA256 и размер совпадают с оригиналом.
Манифест сохраняет исходные статусы, native-проверки, время, review и ограничения.
Его абсолютные `local_raw_evidence`-пути относятся к локальному сырью и не
входят в переносимый bundle. Raw PNG, неудачные прогоны, логи и постеры не включены.
