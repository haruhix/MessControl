# MESS / CONTROL

**Четыре маленьких зуба. Один рот. Семь очень грязных дней.**

Базовый C++ проект для **Unreal Engine 5.8.1 / Windows**: кооперативная игра от третьего лица с постоянным ракурсом камеры и мягкой мультяшной пластикой. Первая играбельная версия, с исходниками Blender и воспроизводимой генерацией контента.

Целевой дизайн: [GDD 0.2](Docs/GDD.md) и [технические решения новых систем](Docs/SystemsDesign.md). Эти документы описывают дальнейшую разработку; реализованный прототип описан в [архитектуре](Docs/Architecture.md).

[Визуальный стиль](Docs/ArtDirection.md) — согласованный референс эмали, влажных тканей, загрязнений и света для будущих моделей.

[Модель и риг игрока](Docs/PlayerAppearance.md) — `SM_Teeth_rig` коллеги, материал, карта костей, физика и настройки щётки.

[Разработка по шагам](Docs/DevelopmentSteps.md) — история проекта. Текущая реализация: [первый день](Docs/Day01.md), с физическими щётками, завтраком из таблицы, фрагментами, язвами, кофейным затоплением и застрявшими волокнами. Восемь больших зубов стоят по четыре с каждой стороны.

## Быстрый запуск

1. Установить Unreal Engine **5.8**, Visual Studio 2022 с **Game development with C++**, Windows SDK и Git LFS. Использованный toolchain: MSVC 14.44, SDK 10.0.22621.
2. Клонировать репозиторий и получить бинарные ассеты:

   ```powershell
   git clone https://github.com/haruhix/MessControl.git
   cd MessControl
   git lfs install
   git lfs pull
   ```

3. Собрать редакторский модуль:

   ```powershell
   .\Tools\Build.ps1
   # Если движок не зарегистрирован в Epic Launcher:
   .\Tools\Build.ps1 -EngineRoot 'E:\UE\UE_5.8'
   ```

4. Открыть `MessControl.uproject`. По умолчанию загружается **Content/Maps/L_Mouth**. Нажать **Play**.

Карта, материалы, модели, звуки, Blueprint-заготовки и Data Assets уже входят в репозиторий. Генераторы запускать для обычного старта не нужно. Проект UE 5.8 не предназначен для открытия в UE 5.6.

Для чистой пересборки закрой Unreal Editor и запусти `RebuildProject.bat` двойным щелчком. Он найдёт UE 5.8, удалит сгенерированные папки сборки и временные данные, затем соберёт `MessControlEditor Win64 Development`. Контент, исходники, конфигурация, автосохранения и локальные пресеты в `Saved` сохраняются.

```powershell
.\RebuildProject.bat                              # Очистка и пересборка
.\RebuildProject.bat "E:\UE\UE_5.8"                # Явный путь к движку
.\RebuildProject.bat -DryRun                      # Проверка без удаления и сборки
```

Можно задать путь к движку через `UE_ROOT` или `UE_ENGINE_ROOT`. Для запуска без ожидания нажатия клавиши установи `MESSCONTROL_NO_PAUSE=1`. PowerShell-версия доступна напрямую: `.\Tools\Rebuild.ps1`.

## Управление

**Новые четыре механики:** [кофе и чистка, статусы и лечение, возрождение, еда и хват](Docs/FirstFourSystems.md). Там описаны назначение файлов, параметры DA и пять проверок через F1.

| Действие | Клавиатура / мышь | Геймпад |
|---|---|---|
| Двигаться по арене | WASD | Левый стик |
| Прыгнуть | Space | A / нижняя кнопка |
| Счищать кофейный налёт | Удерживать ЛКМ возле цели | RB |
| Вытаскивать еду / закреплять зуб | Удерживать E возле цели | X / левая кнопка |
| Переключить уход за собой: ЛКМ чистить, E лечить | C | Нажатие правого стика |
| Бросить удерживаемый предмет / щётку | Q | Y / верхняя кнопка |
| Подгрести в кофе / зацепиться за большой зуб | WASD / удерживать E | Левый стик / X |
| Стукнуть персонажа / игровой зуб арены щёткой | ПКМ | LB |
| Открыть Tooth Lab | F1 | — |
| Создать / подключиться к игре | F2 | — |
| Начать новый забег после финала | R, только у хоста | — |

Подойди к цели и повернись к ней. Несколько зубов могут одновременно работать над одним заданием. Камера смотрит вглубь рта, плавно следует за персонажем и не вращается мышью.

## Семь дней

Обычный запуск проходит [последовательность первого дня](Docs/Day01.md), затем останавливается перед ещё не реализованной пенной вечеринкой. 240 секунд — ориентир, а не общий дедлайн. Старый случайный семидневный стенд (**Coffee Break**, **Snack Attack**, **Wobbly Business**) сохранён с флагом `-MCLegacyDays` для проверки базовых систем.

Все задачи сделаны — короткая передышка и следующий день. Время истекло — незаконченные задачи уменьшают здоровье рта. Если здоровье достигло нуля, забег проигран. Пережить седьмой день с положительным здоровьем — победа. За завершённые задания немного восстанавливается здоровье.

## Играть с друзьями

**В редакторе:** Play → Number of Players = 4, Net Mode = Play As Listen Server.

**Отдельными окнами на одном компьютере:**

```powershell
.\Tools\PlayCoop.ps1 -Players 4
```

**На разных компьютерах:** хост нажимает F2 → Host a new mouth, друзья — F2 → адрес хоста → Join friend. Это прямое подключение к listen server, максимум четыре игрока. Для интернета нужен доступный UDP **7777** или VPN. Steam/EOS, приглашения, автоматический проброс NAT и миграция хоста пока не реализованы.

## Что редактировать

| Ресурс | Назначение |
|---|---|
| `Content/Data/DA_RunRules` | Общие HP, дни, лимит игроков, начальное число зубов арены |
| `Content/Data/DA_PlayerAppearance` | Модель игрока, материал, размер, разворот и положение щётки |
| `Content/Data/DA_ToothCare` | Четыре контакта по 0,5 секунды, лечение, расшатывание, самообслуживание и возрождение |
| `Content/Data/DA_FoodPhysics` | Падение, урон, отлёт, хват, пружина и извлечение еды |
| `Content/Data/DA_ArenaTooth` | Прочность зубов арены, урон, реакции и выпадение; общий порог расшатывания теперь в DA_ToothCare |
| `ARENA / Tooth 01`…`08` в Outliner карты | Положение, модель, масштаб и ID больших зубов рта; отдельный внутренний ряд не создаётся |
| `Content/Data/DA_ToothAnimation` | Squash, stretch, bob, lean, follow through, tempo, anticipation, exaggeration |
| `Content/Data/DA_ToothPhysics` | Отлёт, подброс, порог падения, время ragdoll и подъёма, сила мышц, масса |
| `Content/Art/Rig/SK_ToothHero`, `PA_ToothHero` | Скелет, skin weights, morph targets и семь физических тел с ограничениями суставов |
| `Content/Data/DA_MouthSounds` | Наборы звуков по событиям, случайный pitch и громкость |
| `Content/Data/DA_Coffee`, `DA_Food`, `DA_LooseTooth` | Название, подсказка, число задач, время, скорость работы, штраф |
| `Content/Maps/L_Mouth` | Блокинг, свет, коллизии и четыре точки старта |
| `Content/Blueprints` | Точки расширения персонажа, задания и GameMode |
| `ArtSource/MessControl.blend` | Редактируемые модели и сцена предпросмотра |
| `ArtSource/ToothRig.blend` | Отдельная сцена со скелетом зуба и формами Squash / Stretch |

**F1 Tooth Lab** даёт живое циклическое превью бега, щётки и растяжения. Прокрути панель вниз до Physics: хост может менять физику всех присутствующих зубов, создать тренировочного зуба и проверить падение. Закрой F1 и нажми ПКМ рядом с ним. Сильный удар включает ragdoll; зуб автоматически встаёт, когда под ним есть пол и свободное место.

Save local presets сохраняет `Saved/AnimationTuning.ini` и, у хоста, `Saved/PhysicsTuning.ini`. Чтобы перенести их в общие DA, останови Play и выполни **Tools → Execute Python Script → Tools/Unreal/apply_animation_preset.py** и **apply_physics_preset.py**. Физический preset применяется к следующему запуску после переноса в DA; клиенты не могут менять серверные параметры.

Звуки — короткие оригинальные синтезированные заглушки, включая Whoosh, Hit, Fall, StandUp. Их можно заменить своими SoundWave / SoundCue / MetaSound в DA. Зуб использует процедурную скелетную анимацию, Physics Control для пружинящих конечностей и серверный Chaos ragdoll. Физический хват еды уже работает. Авторские клипы, граф Control Rig, IK кистей и захват опоры при зевании остаются следующими этапами.

Подробнее: [архитектура и сеть](Docs/Architecture.md), [физика и ragdoll](Docs/Physics.md), [12 принципов анимации и параметры](Docs/Animation.md), [проверки](Docs/Validation.md).

## Проверки и восстановление контента

```powershell
.\Tools\Test.ps1 -Mode Unit      # Правила семи дней, поражение, совместная работа и проверки действия
.\Tools\Test.ps1 -Mode Network   # Четыре процесса; движение, RPC и получение общего прогресса
.\Tools\Test.ps1 -Mode CoreNetwork # Четыре процесса: чистка, лечение, еда, ragdoll, расход зуба, хват и утилизация
.\Tools\CaptureCoreDemo.ps1       # Запись того же сетевого сценария из Unreal в MP4
.\Tools\Test.ps1 -Mode Visual    # Скриншоты игры и Animation Lab в Artifacts
.\Tools\Test.ps1 -Mode Ragdoll   # Четыре процесса: удары, падения, подъём, затем совместная работа
.\Tools\Test.ps1 -Mode RagdollVisual # Снимки скелета, падения и восстановления
```

Для генерации исходников нужны Blender 5.x и Python 3.11+:

```powershell
blender --background --factory-startup --python Tools/Blender/create_assets.py
blender --background --factory-startup --python Tools/Blender/create_tooth_rig.py
python Tools/generate_audio.py
```

Затем выполнить `Tools/Unreal/bootstrap_content.py` через Unreal Python, а для скелета — `Tools/Unreal/import_tooth_rig.py`. Первый создаёт отсутствующие ассеты, сохраняет существующую карту и материалы. Второй переимпортирует скелет и заново строит Physics Asset. `MC_REIMPORT=1` разрешает переимпорт статических мешей/аудио; `MC_REBUILD_MAP=1` заменяет сгенерированные объекты с префиксами ART / COLLISION / START / LIGHT. Делай это в отдельной ветке, если уже правил контент вручную. Генераторы Blender перезаписывают собственные `.blend` и FBX: сохраняй авторские правки отдельным файлом или меняй сам генератор.

`Binaries`, `Intermediate`, `Saved`, DerivedDataCache и локальные настройки не хранятся в Git. `.uasset`, `.umap`, `.blend`, FBX, PNG и WAV хранятся через **Git LFS**.
