# Wash'n'Smash · локальная VFX-доска

Только этот проект, Python3.10+ и стандартная библиотека. Нет CDN, облака, внешних API или установки пакетов. Сервер слушает **только127.0.0.1**, порт по умолчанию8765. Приложение не запускает Unreal, команды ОС или игровые сценарии.

Запуск в PowerShell:

```powershell
$env:TEMP='E:/CodexTemp/MessControlReviewBoard'
$env:TMP=$env:TEMP
$env:PYTHONPYCACHEPREFIX='E:/CodexTemp/MessControlReviewBoard/PythonCache'
python E:/DEVGAME/MessControl/Tools/ReviewBoard/server.py --port 8765 --data E:/CodexWork/MessControl/ReviewBoard/reviews.json
```

Открыть `http://127.0.0.1:8765`. Остановка — Ctrl+C. Не используйте0.0.0.0, публикацию порта или прокси в интернет. `--log` задаёт журнал; по умолчанию `E:/CodexWork/MessControl/ReviewBoard/server.log`. Хранилище и журнал обязаны находиться внутри `E:/CodexWork/MessControl`. TEMP/TMP процесса сервер также направляет на E:.

Выберите задачу и версию, посмотрите видео/кадры, явно выберите **свою** оценку0–10 и статус, добавьте комментарий/теги. Кнопка таймкода переносит реальное текущее время native video player в отзыв. «Сохранить отзыв» добавляет неизменяемую запись в историю. Оценка основного агента/техническая проверка находятся отдельно и не заменяют мнение пользователя. В seed нет выдуманных пользовательских отзывов.

## Данные и медиа

Прямую ссылку на карточку и её версию можно сохранить из адресной строки, например `http://127.0.0.1:8765/?task=active-driver`. При выборе новой версии сначала показывается доступная GIF; исходное MP4 остаётся в переключателе материалов для просмотра движения с полной частотой кадров и отзыва с таймкодом.

Версионируются только шесть файлов в `Tools/ReviewBoard`. Generated reviews/logs/медиа остаются на E: вне Git. `reviews.json` содержит только введённые пользователем записи. Запись защищена thread lock и atomic replace временного файла в той же E:-папке. Неизвестное/повреждённое хранилище сервер не затирает; исправьте копию вручную после остановки. Одновременно используйте один экземпляр сервера для одного data-файла.

`seed.json` — явный проектный manifest, перечитывается при запросе. Для новой версии добавьте объект в `tasks[].versions`, сохраните предыдущие версии. Для нового клипа/кадра добавьте уникальный объект в `media`:

```json
{"id":"heal-v2-video","kind":"video","label":"Лечение v2 — настоящий solo","path":"E:/CodexWork/MessControl/PassiveVFX_20261029/Preview/heal_v2.mp4"}
```

Затем добавьте ID в `mediaIds` нужной версии. Используйте `rootReview` только для фактической оценки основного агента, `native` — для реально выполненной технической проверки; непроверенные поля остаются pending/null. Перезапуск при валидном обновлении seed не нужен; обновите страницу.

HTTP получает **только manifest ID**, никогда файловый путь. Разрешены `.mp4`, `.png`, `.jpg`, `.webp`, `.gif` только под `E:/CodexWork/MessControl`; GIF указывается как `kind: "image"`. Real resolved paths проверяются, выход через symlink/junction запрещён. Пропавший файл отображается как недоступный. Сервер не отдаёт каталоги, исходники, seed/data-файлы или произвольные пути. MP4 потоково читается блоками64KiB; single byte ranges и HEAD поддерживают native player/перемотку.

API: `GET /api/state`, `POST /api/feedback` с JSON. Feedback принимает taskId/versionId, integer score0..10, status accepted/rework/rejected/pending, comment≤5000, разрешённые tags, необязательный timecodeSeconds. Неизвестные поля/версии/теги отклоняются. Host и Origin ограничены локальным адресом, CORS отключён; JSON сохраняется как текст, DOM не интерпретирует комментарий как HTML. Сервер не исполняет код, feedback или действия из комментариев.

Сначала нужен убедительный образец лечения в настоящей игровой камере, затем перенос его языка объёма и движения на остальные события.
