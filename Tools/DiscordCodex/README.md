# MessControl в Discord через локальный Codex

Текстовый бот для обсуждения проекта с коллегой: что можно реализовать, насколько это сложно,
где находится механика, как её отключить или удалить. Использует установленный Codex и вход
через аккаунт ChatGPT. Отдельный OpenAI API-ключ не нужен; действуют лимиты аккаунта Codex.
ПК должен быть включён и подключён к интернету. Модель работает на серверах OpenAI.

## Первый запуск

1. В [Discord Developer Portal](https://discord.com/developers/applications) создай приложение
   `MessControl Assistant`. На странице **Bot** получи токен через **Reset Token**.
2. На странице **Installation** включи **Guild Install**, добавь scopes `bot` и
   `applications.commands`. Разрешения: **View Channels**, **Send Messages**,
   **Send Messages in Threads**, **Attach Files**, **Read Message History**.
   По **Install Link** добавь бота на ваш сервер. Поле **Interactions Endpoint URL** оставь пустым:
   программа получает команды через Gateway и не требует публичного адреса, ngrok или проброса портов.
   **Message Content Intent** включать не нужно: содержимое сообщений с упоминанием доступно боту без него.
3. В Discord включи **Настройки → Расширенные → Режим разработчика**. Скопируй ID сервера,
   свой ID и ID коллеги через контекстное меню. При желании скопируй ID отдельного канала.
4. Из корня проекта запусти:

   ```powershell
   .\Tools\DiscordCodex\Setup.ps1
   .\Tools\DiscordCodex\Start.ps1
   ```

   Мастер запросит ID и токен **в локальном терминале**. Токен вводится скрыто и сохраняется с
   шифрованием Windows DPAPI в `%LOCALAPPDATA%\MessControlDiscord\token.dpapi`, вне репозитория.
   Не отправляй токен в переписку. Конфигурация без токена лежит в `Saved/DiscordCodex/config.json`.
   Укажи обоих пользователей. Операторов `fetch/pull` можно оставить пустыми.

Токен можно сохранить отдельно до ввода ID: открой `Set-DiscordToken.cmd`, вставь его в скрытое
поле и нажми **Save**. Окно проверяет, что Discord принимает токен бота, и сохраняет его в тот же
зашифрованный файл. Затем мастер `Setup.ps1` предложит использовать уже сохранённый токен.

Для следующих запусков можно открывать `Start.cmd` двойным щелчком. Остановка — **Ctrl+C**.
Node.js 22+ должен быть доступен в PATH. Codex ищется в PATH или в каталоге установленного
десктопного приложения; скрипт установки сохраняет найденный путь.

## Разговор и команды

```text
@MessControl Assistant можем ли добавить разные эффекты еды? Насколько это сложно?
@MessControl Assistant где задаётся скорость чистки щёткой?
@MessControl Assistant как отключить волну боли от язвы?
@MessControl Assistant что затронет удаление механики кофе?
@MessControl Assistant задача оформи обсуждённое отключение в задачу
```

| Команда | Результат |
| --- | --- |
| `/mc ask question:…` | Обсуждение возможности, сложности, отключения или другого вопроса |
| `/mc find query:…` | Поиск кода, Blueprint, ассета или настройки |
| `/mc task description:…` | Черновик задачи: цель, план, критерии готовности и проверки; Markdown в приложении |
| `/mc git action:status` | Ветка, локальные правки и конфликты |
| `/mc git action:log` | Последние 12 коммитов |
| `/mc git action:updates` | Входящие коммиты по данным последнего fetch |
| `/mc git action:fetch` | Обновить удалённые ссылки и показать входящие изменения |
| `/mc git action:pull` | Получить изменения только через fast-forward при чистой рабочей папке |
| `/mc reset` | Сбросить обсуждение в текущем канале |
| `/mc stop` | Прервать текущий ответ Codex в этом канале |
| `/mc help` | Справка |

Бот помнит **обращения к нему** от обоих пользователей в одном канале. Обычная переписка не
собирается. Для задачи из неадресованного боту обсуждения передай описание в `/mc task`.
Discord-ветка имеет свой контекст. Сессии восстанавливаются после перезапуска.
Готовые задачи сохраняются в `Saved/DiscordCodex/tasks/`; длинные ответы прикладываются файлом.
Публикация Issues, коммиты и изменения исходников в этот прототип не входят.

## Доступ к проекту

Codex получает каталог MessControl и `AGENTS.md`. Используется отдельная сессия, а не текущий
чат десктопного приложения. Из глобальной конфигурации подключаются только `codebase_memory`
и `messcontrol_assets`, с разрешёнными инструментами чтения и поиска. Глобальный `config.toml`
не изменяется. Остальные MCP отключаются только в процессе бота.

Вопросы и задачи выполняются с `sandbox: read-only`. Команды Git запускает сама программа
с фиксированными аргументами, отдельно от модели. `fetch/pull` разрешены только пользователям
из `operatorUserIds` при `allowGitUpdates: true`. Незавершённое слияние, конфликты, локальные
правки и расхождение веток не исправляются автоматически. Работает только один запрос одновременно,
остальные ждут в ограниченной очереди. Сообщения ботов, вебхуки, личные сообщения и пользователи,
не указанные в конфигурации, игнорируются. Ответы не вызывают массовых упоминаний.

Если индекс устарел, помощник сообщает это и использует исходники; он не запускает сборку Unreal.
Для настройки индексов смотри `Docs/ProjectIndex.md`. Переиндексация не нужна из-за добавления самого бота.

## Проверка и диагностика

```powershell
# Вход и доступность MCP; без Discord-токена и генерации моделью
.\Tools\DiscordCodex\Start.ps1 -Mode doctor

# Один реальный запрос: индексы и Git, расходует лимит Codex
.\Tools\DiscordCodex\Start.ps1 -Mode smoke

# Быстрая проверка только ответа модели
.\Tools\DiscordCodex\Start.ps1 -Mode smoke -Simple

# Автоматические проверки без Discord и без модели
cd Tools\DiscordCodex
npm.cmd test
```

При смене версии Codex сначала повтори `doctor` и `smoke`: app-server развивается.
После обновления приложения `Start.ps1` автоматически ищет новый Codex, если сохранённый файл
больше не существует. При запуске напрямую через Node можно повторить `Setup.ps1` или заменить
`codexExecutable` в `Saved/DiscordCodex/config.json` на актуальный путь.
При ошибке входа выполни `codex login` и выбери ChatGPT.
Если бот не запускается после аварии, проверь, что старый процесс остановлен, и удали
`Saved/DiscordCodex/bot.lock`. Если `/mc` не появляется, проверь Guild Install,
scope `applications.commands` и ID сервера. Для упоминаний нужен именно тег бота.

Протокол: [Codex app-server](https://learn.chatgpt.com/docs/app-server).
Вход: [Codex authentication](https://learn.chatgpt.com/docs/auth).
Discord: [Gateway](https://docs.discord.com/developers/events/gateway).
