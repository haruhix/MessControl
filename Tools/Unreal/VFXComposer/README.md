# VFX Composer: направленная проверка

Актуализация 2026-10-31: `check_composer.py` и `save_action_templates.py` ниже сохраняют исторический ingredient API. После объединения окон этот API не является проверенным сценарием нового action/event workspace. Не используйте их результат как подтверждение текущего интерфейса. Актуальные проверки общего окна, независимых слоёв и native adapters описаны в `Docs/Validation/ComposerActionWorkspace_20261031.md` и `Docs/Validation/ComposerAdapters_20261031.md`; миграция всех владельцев — в `Docs/VFXComposerMigrationInventory_20261031.md`.

Рецепт `check_composer.py` подготовлен для собранного UE 5.8.1 Editor. Сам скрипт не собирает проект, не запускает PIE и не открывает Composer автоматически. Результаты его выполнения и визуальная приёмка — разные проверки.

## Сохранённая фикстура

Единственное место записи Unreal-пакета:

`/Game/Tests/VFXPractice/Compositions/DA_ComposerSmoke_20261030`

Три слоя: две независимые ссылки на `NS_Practice_FoamBasics` с разными transform/binding/delay и один `NS_Rocket_Impact` как контактный акцент с типизированными User overrides. Это техническая демонстрация композиции, **не утверждённый эффект лечения**. Дублирование слоёв не дублирует и не изменяет NS. Система FoamBasics не имеет User-параметров; её размер здесь меняет transform экземпляра, а не скрытый параметр исходника.

При первом запуске сохраняется только новая DA. При повторе существующий ассет читается без перезаписи; ручные изменения могут привести к несовпадению проверок, но сохраняются. Скрипт сравнивает SHA256 файлов двух исходных NS и dirty package flags до/после. Он не сохраняет, не перезагружает, не откатывает и не снимает dirty-флаг с чужих ассетов. Отчёт остаётся на E: в `E:/CodexWork/MessControl/Validation/VFXComposer_20261030/FixtureScript/`.

Запуск после явного согласованного rebuild через Unreal Python:

```python
exec(compile(open(r"E:/DEVGAME/MessControl/Tools/Unreal/VFXComposer/check_composer.py", encoding="utf-8").read(), r"E:/DEVGAME/MessControl/Tools/Unreal/VFXComposer/check_composer.py", "exec"))
```

## Проверка окна основным агентом

1. Открыть **Tools → Wash n Smash → VFX Composer** и загрузить указанную DA. Проверить, что выбранная исходная DA остаётся чистой, а изменения происходят в рабочей копии.
2. Play: появляются два слоя пены с интервалом 0,65 с, акцент — в 1,5 с. Pause останавливает время и частицы, Play продолжает. Reset возвращает время к нулю и запускает заново.
3. Mute/Solo: изменять только рабочую копию; выключенный слой не включается от Solo. Разные экземпляры одного NS сохраняют разные transform и timing.
4. Выбрать слой акцента, прочитать параметры, изменить один float/color override. Проверить отдельный экземпляр и неизменность source NS. Для FoamBasics список User-параметров должен быть пустым, без выдуманных Width/Color inputs.
5. Передвинуть timeline и отпустить. В окне остаётся пауза на достигнутом времени; GPU/эффекты с историей обозначены приблизительными. Это не обещание точной GPU-перемотки.
6. Включить движение: движется зубик в исходной позе, Subject-слой следует за ним. Composition/World слои остаются у своих якорей. Проверить пол, полезный ракурс и читаемость на зубике. Это не анимация персонажа.
7. Bounds и Focus: видны текущие границы Niagara компонентов. Исходные fixed bounds NS не записываются. Скрытие пола/окружения не меняет общий AssetViewer профиль.
8. Сохранить **новый отдельный** preset через окно. Проверить закрытие с несохранённой рабочей копией, Cancel/Discard и Undo/Redo. Не перезаписывать учебную фикстуру ради демонстрации Save As.
9. Закрыть окно и открыть заново; проверить, что исчезли только owned preview actors/world, обычная карта/PIE/выбор/несохранённые ассеты не затронуты.
10. Основной агент лично смотрит короткий ролик/GIF реального окна. Записать функциональный результат отдельно от художественной оценки и сохранить медиа на E: вне Git.

## Направленные native проверки

Только отдельным согласованным запуском: `MessControl.VFX.Composer.Validation`, `MessControl.VFX.Composer.ParameterIsolation`, `MessControl.VFX.Composer.ScheduleAndSnapshot`.

Python-скрипт не вызывает lifecycle на CDO и не спавнит временный actor в открытый level ради этих проверок. Изолированный viewport проверяет настоящий runtime actor; native fixtures проверяют его расписание, snapshot и типы. Наличие reflected методов в Python само по себе не считается проверенным исполнением.

## Пределы результата

Сохраняется `UMCVFXComposition` с независимыми Niagara слоями, **не объединённая NS**. Это не интеграция в DT_Perks, actual damage/cleaning, сетевую доставку или loading readiness. Перед подключением preset к игре нужны отражённая ссылка из используемой локации/DT/manifest, подготовка всех ресурсов и первый показ до/после readiness. Тёплый Editor не доказывает холодные packaged PSO, отсутствие shader/streaming задержек, приемлемый overdraw или GPU-бюджет.
