# Источники «Пенной мастерской»

Снимок: 30.10.2026. Целевая установленная версия проекта — UE **5.8.1**; публичная документация Epic — ветка **5.8**. HTML работает автономно: ссылки не загружаются до явного перехода пользователя. Ни видео авторов, ни проекты/ассеты не скачивались и не переносились в MessControl.

## Локальные основания

- [author_sponge_soap_trail.py](../Unreal/author_sponge_soap_trail.py): авторский рецепт одного stateful CPU world-space sprite emitter; Spawn Per Unit; defaults Width84/Lifetime2.4/Opacity.48/SpawnSpacing18; clamp Width30..180/Lifetime.35..3/Spacing16..80; PreviewMotion/PreviewSpeed; материал и текстура.
- [MCSpongeSoapTrail.cpp](../../Source/MessControl/Private/MCSpongeSoapTrail.cpp): текущее чтение velocity/support, выключение PreviewMotion до Activate, native row overrides и graceful Deactivate. Широкие допустимые C++-диапазоны не отменяют clamp внутри Niagara.
- [ReviewBoard README](../ReviewBoard/README.md): локальная доска 127.0.0.1:8765, отдельное хранение реальных оценок/истории; пользовательская оценка лечения не заменяется оценкой агента.

Пакеты и живая сцена не инспектировались автором HTML; снимок рецепта не является live-readback. Изменения Unreal выполняет основной агент отдельно. Переданное им наблюдение: preview-камера Trail была сохранена на Z−215/pitch0, плоскость пены около Z1.5; новый сохранённый ракурс (−400,−500,+500), pitch−37.985°, yaw51.34°, orbit=false. Основной агент **лично увидел пену в preview** после этой коррекции и временного выключения белого HDRI-фона. A/B подтверждает различимость на сером фоне и почти потерянный контраст на белом, а не физическое occlusion геометрией. Скрытие HDRI-сферы transient, автосохранение Background-off не подтверждено: после переоткрытия нужен Background off или серый preview profile. Видимость — отдельный результат от художественной приёмки.

Финальная отдельная проверка основного агента на обычном Editor: исходное `bThrottleCPUWhenNotForeground=True`, при этом `t.IdleWhenNotForeground=0`. Windows foreground lock не дал MCP-выбору окна перевести системный фокус с Codex на Unreal. Первоначальный WGC-клип `4sPreviewWindow.mp4` был пустым/почти не обновлялся. Временное `bThrottleCPUWhenNotForeground=False` дало движение пены и fade в повторе `WGCPreviewWindow02/NiagaraPreview.mp4`, `Contact.png` и animated GIF; после записи исходное True восстановлено. В гайд добавлен порядок «активное окно → tick/realtime → particle count → renderer/material». Параметр не выключается HTML и не предлагается как обязательное постоянное предпочтение; пользователь может осознанно изменить Editor Preferences → Performance → Use Less CPU when in Background для параллельной работы.

## Учебная карта VFXPractice

Добавлено 30.10.2026 по реализации основного агента и прочитанным локальным recipes. Карта `/Game/Tests/VFXPractice/L_VFXPractice` использует `BP_PracticeStation`, `BP_PracticeBootstrap` и нативный `MCVFXLabGameMode`. Шесть зон содержат восемь выбираемых станций: Free Play, Ground Trail, Heal Studio, Impact, Slope + Wall и три экземпляра Contrast (Dark/Pink/Light). Зубики — нативные `MCToothCharacter` для reference; управление — свободный spectator, без playable tooth.

- [VFXPracticeSandbox.md](../../Docs/VFXPracticeSandbox.md) — пользовательский порядок открытия, редактирования и повторов.
- [author_practice_map.py](../Unreal/VFXPractice/author_practice_map.py) — отдельный World, назначенные учебные NS, slope20°, reference-зубики, локальные fixtures, native lab navigation и Bootstrap.
- [author_practice_blueprints.py](../Unreal/VFXPractice/author_practice_blueprints.py), [recipes](../Unreal/VFXPractice/recipes/Station_EventGraph.dsl) — Niagara-компонент `PracticeFX`, локальное движение источника, reset и overrides Trail. `TrailDirection` задаёт локальную ось движения; `SurfaceNormal` — мировую нормаль; Velocity/Direction для Niagara рассчитываются в мире. Поля actor `TrailWidth/Lifetime/Opacity/SpawnSpacing` перекрывают соответствующие NS-defaults.
- [isolate_practice_renderers.py](../Unreal/VFXPractice/isolate_practice_renderers.py) — переназначение renderer-материалов, родителей material instances и текстур на учебные копии. Сохранены study NS `/Game/Tests/VFXPractice/Effects/NS_Practice_Burst`, `NS_Practice_Trail`, `NS_Practice_HealSeed`, `NS_Practice_Impact`. Material Functions, Material Parameter Collections и color curves остаются общими read-only зависимостями; общие runtime-ресурсы персонажа также не изолированы для учебной правки. Полное копирование всех transitive dependencies не заявлено.
- [Bootstrap_EventGraph.dsl](../Unreal/VFXPractice/recipes/Bootstrap_EventGraph.dsl) — подготовка известных ресурсов до запуска lab; при ошибке подготовки эффекты остаются остановлены. Это устройство реализации, не доказательство холодного packaged PSO.

`NS_Practice_HealSeed` — копия `NS_Sponge_End`, явно подписанная пенная заготовка для создания своего Healing NS. Heal Studio не изменяет HP и не подключён к игровому heal trigger. Impact — визуальная проба, не подтверждение настоящего hit крюка. Следы двигают источник эффекта; очистка пола, реальная способность губки и ходьба по стенам здесь не реализованы.

Итог основного агента: **короткая solo-проверка прошла, 12/12**, текущий `E:/CodexWork/MessControl/Validation/VFXPracticeSandbox_20261030/SoloReport.json` имеет status=passed и 12 true-полей. Наблюдались gate до release, активность всех восьми станций, движение Trail, пауза, reset (`Cycles=1`), открытие/закрытие native-навигации, отсутствие day scheduler и неизменный диск исходного BP персонажа. Команды контроллера вызывались через reflection; физические горячие клавиши не проверялись. Gallery/checked=0 — унаследованные подписи общего lab, а не автоматическая оценка упражнения.

Основной агент лично посмотрел runtime-движение и кадры. Сохранены `SandboxTour.mp4` (floating-окно 1286×760, viewport 1280×720) и `SandboxTour.gif` около 14,4 с в той же папке E:. Ссылки на локальные файлы даны в [VFXPracticeSandbox.md](../../Docs/VFXPracticeSandbox.md); HTML не встраивает локальные медиа через HTTP. Художественная приёмка открыта. Автор этого текстового обновления не использовал Editor/MCP. Сеть, Windows build/cook/package, голос, холодный packaged PSO и GPU/overdraw не проверялись.
