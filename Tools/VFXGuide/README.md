# Пенная мастерская · MessControl

Откройте `E:/DEVGAME/MessControl/Tools/VFXGuide/index.html` обычным браузером. Сервер, интернет, пакеты, CDN и API не нужны. Ссылки на документы проекта и внешние первоисточники открываются только по нажатию.

Внутри: маршрут первых шагов, отдельная карта практики в Unreal, точные пути NS, интерактивный стек, учебная Canvas-схема, репетитор/пять заданий с раздельными черновиками, текущая и предлагаемая схемы интеграции VFX, диагностика, 26 Q&A, 4 мини-проверки, шаблон отзыва с рисованием и JSON. Репетитор — чат с агентом; встроенного LLM/анализа/отправки в HTML нет.

Единственный рабочий вход: **Tools → Wash n Smash → VFX Composer** / **`MC.VFXComposer`** / editor API **`OpenVFXComposer`**. Маршрут: **контекст → событие → несколько независимых NS-слоёв**. Слева зубик/воспроизведение и общий каталог, в центре события, справа общая галерея и параметры. Клик карточки — временная проба; «Добавить» или перенос на событие меняет черновик; «Применить в игре» отдельно сохраняет и назначает результат.

Каталог использует общие runtime definitions/provider metadata. **«Сценарий + редактирование VFX»** и **«Сценарий · VFX-привязка впереди»** обозначают разные возможности: родную механику можно смотреть, даже когда назначение нового Niagara ещё не реализовано. Метаданные события без adapter не выдаются за работающий preview. Полный аудит VFX всех боссов и карт пока не завершён.

Публичные отдельные окна VFX Elements, VFX Layers и Perk Action Preview сняты с маршрута; совместимые старые entry points перенаправляются в единый Composer. Существующие композиции, исходники и профили сохранены. Старые проверки не удалены, но они относятся к своим версиям.

Основной новый формат — runtime `UMCVFXComposition`: исходные проектные NS из фильтра «Все» остаются самостоятельными слоями. Строгий single-NS экспорт — отдельная дополнительная операция, не обязательный барьер галереи/обычного сохранения. Этот runtime-проход и новые контексты **ещё проверяются**, не объявлены готовыми. Пассивки пока не мигрированы на заменяемый `DT.VFXProfile`. [Текущий checkpoint](../../Docs/Validation/ComposerActionWorkspace_20261031.md), [27 source-сценариев пассивок](../../Docs/Validation/ComposerPassiveScenarios_20261031.md).
