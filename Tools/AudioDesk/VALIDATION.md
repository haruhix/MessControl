# Audio Desk 1.1.0 — проверка поставки

Проверено 24 октября 2026 на Windows 11 x64, включая штатный Windows PowerShell 5.1. Игровые ассеты и настройки Unreal не изменялись; интеграция одобренного профиля в игру остаётся отдельным этапом.

- **27 Python-проверок**: сохранение и резервная копия, импорт/экспорт, HTTP и byte ranges, фильтрация таймингов, перенос установки, неизменность существующего профиля, состав публичной библиотеки и SHA256 всех файлов.
- **17 Node-проверок**: контекст и длительность кандидатов, границы допустимого времени, неизвестные метаданные, ручной trim и исключение длинных SFX из шагов.
- **9 проверок лаунчера** в PowerShell 5.1: синтаксис, пути, SHA256, LFS-указатели, распаковка, сохранение прежней библиотеки, защита чужих папок и ZIP traversal.
- Реальный `Start.bat` из каталога с пробелами и кириллицей при `PATH`, содержащем только системные папки Windows: приложение распаковано и запущено без доступных в `PATH` Python, FFmpeg, Node и Git.
- У собранного EXE через HTTP проверены 550/550 доступных аудиофайлов, 107 событий, 52 стартовых предложения и отсутствие стартовых одобрений. Для WAV и OGG проверены 600 точек waveform, byte ranges и конвертированный preview встроенным FFmpeg.
- Через API собранного EXE проверены живое сохранение одобрения и русской заметки, резервная копия, именованный профиль и экспорт в `data`. Проверочное одобрение снято.
- Повторный запуск использует тот же PID. `Stop.bat` останавливает свой сервер; перезапуск сохраняет рабочий профиль побайтно. Вторая копия выбирает другой порт; остановка первой не затрагивает вторую.
- Встроенным ffprobe отдельно проверены параметры всех 550 файлов без ошибок. Личный профиль исходной внешней установки сохранён без изменений.

Runtime собран из исходников в этой папке с Python 3.14.2 и PyInstaller 6.19.0. Версия встроенного FFmpeg, исходники и лицензии перечислены в [ThirdParty/README.md](ThirdParty/README.md). Архивы проверяются по manifest при распаковке.

Это локальные проверки переносимого приложения на одной машине, а не проверка на отдельной чистой Windows. Сборка, cook, PIE и сетевые тесты игры в эту задачу не входили и не запускались.
