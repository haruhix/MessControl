# MessControl Audio Desk

Локальное приложение для прослушивания, подбора и согласования звуков без запуска Unreal Editor. Windows 10/11 x64, обычный браузер. Python, FFmpeg и дополнительные пакеты на компьютере коллеги не нужны.

## Запуск

1. Обнови репозиторий и открой папку `Tools/AudioDesk`.
2. Запусти `Start.bat`. При первом запуске распакуются приложение и библиотека; откроется браузер.
3. Для остановки сервера запусти `Stop.bat`. Закрытие вкладки сохраняет работающий сервер; повторный `Start.bat` открывает тот же экземпляр.

Приложение выбирает свободный локальный порт от 8765 до 8785. Оно не требует прав администратора и работает только на `127.0.0.1`. Папка должна быть доступна для записи. Можно скопировать всю папку AudioDesk в другое место, включая путь с пробелами и кириллицей.

`runtime.zip` и `library.zip` хранятся в Git LFS. Если вместо архива скачался маленький файл указателя, запуск сначала попробует Git LFS, затем загрузит нужные архивы с GitHub и проверит SHA256. В этом случае для первого запуска нужен интернет. После распаковки приложение работает локально. Для явного скачивания только этих двух архивов:

```bat
git lfs pull --include="Tools/AudioDesk/runtime.zip,Tools/AudioDesk/library.zip" --exclude=""
```

## Подбор звуков

В комплекте 550 аудиофайлов, 107 слотов игровых событий и 52 предварительных назначения. Одобренных назначений при первом запуске нет. Библиотека включает 527 CC0 файлов и 23 оригинальных звука проекта; источники и лицензии перечислены в [THIRD_PARTY_AUDIO.md](THIRD_PARTY_AUDIO.md). Другие приобретённые или скачанные паки можно подключить локально через «Открыть папку».

Выбери событие справа: библиотека покажет кандидатов по контексту и допустимой длительности. Для шагов длинные SFX скрываются. Отключи «Кандидаты для события», чтобы увидеть весь набор. Прослушай звук, перетащи его в событие, при необходимости измени начало, конец, громкость или петлю, затем нажми «Одобрить и дальше». Несколько файлов можно бросить вместе; Shift при перетаскивании из библиотеки добавляет вариант к существующим.

Свои файлы можно перетаскивать из Проводника на область добавления или прямо на событие. Загруженные файлы копируются в папку приложения. При подключении папки аудио остаётся в исходном месте.

Изменения сохраняются автоматически: назначения, статусы, заметки и параметры клипа. Вверху отображается «Черновик сохранён» после ответа сервера. «Сохранить как…» создаёт именованный профиль; «Экспорт профиля» сохраняет JSON для дальнейшей интеграции. Приложение не импортирует файлы в Unreal: одобрения и экспорт предназначены для следующего этапа подключения звуков в игре.

Клавиши: **Пробел** — воспроизведение/пауза, **A** — одобрить, **R** — отклонить, **N** — следующий кандидат, **/** — поиск. Они действуют вне текстовых полей.

## Где хранятся данные

Рядом с батниками создаётся папка `data`: рабочий черновик, резервная копия, именованные профили, экспорт, загруженные файлы, метаданные и логи сервера. Она исключена из Git. Для переноса личной работы копируй всю папку AudioDesk вместе с `data`. Файлы из внешних подключённых папок нужно перенести отдельно и подключить на новом компьютере; экспорт JSON сам по себе аудиофайлов не содержит.

Не удаляй `data` при обновлении. `Start.bat` не заменяет существующий рабочий профиль стартовыми назначениями. При обновлении встроенной библиотеки предыдущая управляемая копия сохраняется в `.library.previous.*`; свои файлы удобнее держать в `data` или отдельной подключённой папке. Личная рабочая копия этого инструмента вне репозитория обновлением не затрагивается.

Если запуск завершился ошибкой, сообщение останется в окне батника. При сбое уже запущенного сервера смотри `data/server.stderr.log` и `data/server.stdout.log`. Для диагностики без открытия вкладки: `Start.bat -NoBrowser`. Можно указать `-Port 8770`, `-DataDirectory "D:\AudioDeskData"` или `-NoDownload`; при нестандартной папке данных передай такой же `-DataDirectory` в `Stop.bat`.

## Разработка и пересборка

Исходники сервера находятся в `app.py`, интерфейс — в `web`, карта игровых событий — в `catalog.json`. Для запуска из исходников требуется Python 3.10+; FFmpeg/ffprobe обеспечивают определение параметров, waveform и конвертацию аудио. `Build.ps1` собирает самостоятельный Windows runtime через PyInstaller:

```powershell
.\Build.ps1 -Python python -MediaDirectory "E:\AudioDeskBuild\media" -Version 1.1.0 -DownloadBaseUrl "https://media.githubusercontent.com/media/haruhix/MessControl/main/Tools/AudioDesk"
```

В `MediaDirectory` должны находиться совместимые `ffmpeg.exe`, `ffprobe.exe` и DLL их shared-сборки. Лицензии, исходники FFmpeg и рецепты сборки сохранены в [ThirdParty](ThirdParty/README.md). `-RepackOnly` пересоздаёт архив и manifest из уже собранной `.build/dist/AudioDesk` без пересборки. После изменения серверного кода или интерфейса нужна полная пересборка. `runtime-manifest.json` и `runtime.zip` обновляются вместе; при изменении стартовой библиотеки вместе обновляются её архив, manifest и seed-файлы.

Проверки из этой папки:

```powershell
python -B -m unittest test_backend test_timing test_portable test_public_library
node --test test_candidates.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File .\test_launcher.ps1
```

Тесты используют временные каталоги на `E:`. Упаковка этого инструмента не запускает сборку, cook или тестирование игры.

Результаты проверки собранного приложения: [VALIDATION.md](VALIDATION.md).
