# Управление с геймпада

Windows-билд использует стандартные кнопки Unreal для геймпада. Названия ниже —
по раскладке Xbox. Для контроллера PlayStation через Steam Input используются
соответствующие позиции кнопок: A = крест, B = круг, X = квадрат, Y = треугольник.

| Действие | Кнопка |
| --- | --- |
| Движение / плавание / лазание | Левый стик |
| Вращение камеры | Правый стик |
| Прыжок / отпрыгнуть / прыжок на язычок | A |
| Основное действие выбранного инструмента | RT или RB; удерживать для непрерывного действия |
| Отдельный удар | LT |
| Взаимодействие / держать предмет | X; удерживать |
| Бросить предмет | Y |
| Держаться за опору / защита | LB; удерживать |
| Рывок / бег | Нажать левый стик (L3) |
| Самоочистка | Нажать правый стик (R3), затем основное действие |
| Щётка / кирка / нож / спрей | Крестовина: ← / ↑ / → / ↓ |
| Активировать накопленный усилитель | B |
| Меню | Start / Menu |
| Таблица игроков | View / Back; удерживать |

В меню: левый стик или крестовина перемещают фокус, A выбирает, B возвращает
назад. В меню наград выделенная карта подсвечивается; стик или крестовина
меняют выбор, A подтверждает, Y перебрасывает личный набор перков, если переброс
ещё доступен. B позволяет отказаться от необязательной награды.

Эмоции и сигналы открываются через Start → Emotes / Сигналы: ← / → меняют
категорию, ↑ / ↓ выбирают пункт, A подтверждает, B закрывает.

После ввода с геймпада подсказки действий и уроков показывают его кнопки.
Мышь и клавиатура продолжают работать; их ввод возвращает прежние подсказки.
Правый стик поворачивает камеру со скоростью, не зависящей от FPS, и учитывает
мёртвую зону стика. Чувствительность `GamepadCameraTurnRate` задаётся отдельно
от чувствительности мыши в параметрах персонажа.

Для запуска через Steam используй `Start_Steam.cmd`. Если контроллер не
распознаётся Windows как XInput, включи для него Steam Input и используй
раскладку геймпада. Физическую совместимость конкретной модели следует
проверить на ней; автоматическая проверка использует события геймпада Unreal.

Проверка: `Tools/TestGamepad.ps1`; для готового билда передай `-BuildRoot`
с путём к папке `Windows`. Проверяются главное меню, настройки, движение,
камера и мёртвая зона, инструменты, удержание и отпускание RT, удар LT,
усилитель B, пауза, эмоции, переброс и получение перка. По умолчанию игровой
сценарий выполняется при 30 и 120 FPS; сетевые тесты не запускаются.
