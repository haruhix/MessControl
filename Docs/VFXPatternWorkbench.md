# Паттерны VFX и возможная проектная мастерская

Это учебная карта и исходное предложение. Первое подмножество реализовано как проектная вкладка Composer (слои NS, компонентные привязки, тайминг и preview); текущее состояние — [VFXComposerMVP.md](VFXComposerMVP.md). Полная библиотека восьми адаптеров и DT VFXProfile ещё не реализованы. Интерактивная схема — [Tools/VFXGuide/index.html#patterns](../Tools/VFXGuide/index.html#patterns). Первый практический урок остаётся FoamBasics.

| Паттерн | Источник данных | Пример MessControl |
|---|---|---|
| Прикреплённый эффект | Component/socket + относительный transform | Пена возле зубика при лечении |
| Частицы на поверхности | Выбранный Skeletal Mesh Component + sampling | Блики эмали на теле |
| Материальный overlay | Mesh Component + material/маска/кривая | Полоса восстановления эмали |
| Снаряд | Игровой actor: запуск, позиция, скорость, hit/end | Ракетница |
| Попадание | Фактическая мировая точка + нормаль | Контакт крюка |
| След в мире | Последовательность поддерживаемых позиций | След губки |
| Связь двух точек | Два актуальных мировых endpoint | Трос крюка |
| Область/предупреждение | Игровая форма, радиус и тайминг | Предупреждение гранаты |

«Поверх меша» не является одной операцией. Прикрепление двигает источник целиком. Семплирование поверхности в Spawn берёт позу рождения; для постоянного следования анимации нужны соответствующие Update/reproduction-операции. Overlay меняет поверхность материалом и не требует превращать её в частицы. Поддержка CPU/GPU, sampling/масок и отдельных частей модульного персонажа проверяется на конкретном меше.

В Unreal уже есть Niagara modules/templates, пользовательские параметры и [Emitter Summary](https://dev.epicgames.com/documentation/unreal-engine/summary-quick-start-guide). Summary позволяет сгруппировать выбранные настройки и дать им понятные названия. Пример документации использует Fluids, но Summary не требует включать NiagaraFluids. В проекте уже импортирован [Niagara Examples Pack](https://www.fab.com/listings/0e188eca-4e54-4fb2-a9ed-d8b8a565e600); исходные пакеты рассматриваем read-only до копирования.

Минимальная будущая вкладка Editor: выбрать паттерн → персонажа/меш/точки → совместимый NS → проверить Play/Pause/Reset в учебном мире → сохранить профиль. Она готовит повторяемые привязки и показывает ограниченную панель настроек; Niagara остаётся редактором эффекта. Для снаряда нужны отдельные визуальные роли Launch/Travel/Impact/End, а не один NS, которому передали название «ракета».

`DT_Perks → VFXProfile` с именованными слотами пока не реализован; актуальный проектный план — [PerkVFXDataWorkflow.md](PerkVFXDataWorkflow.md). Нельзя объявлять этот HTML интерфейсом назначения в Unreal. Урон, коллизии, очистка, физика и подтверждённые игровые события остаются авторитетной игровой логикой.

Первые три практики: (1) FoamBasics — один literal параметр и полный lifetime; (2) прикреплённая пена у зубика — проверить движение и остановку без закрытия лица; (3) projectile-песочница — связать запуск, полётный хвост и попадание с реальным учебным actor. Второй и третий отдельными готовыми пресетами этим документом не заявлены.

Проверка данного дополнения: HTML/JS/переключение всех восьми схем. Сборки Editor, installs, сетевые тесты, авторинг новых Unreal-паттернов и художественная приёмка не выполнялись.
