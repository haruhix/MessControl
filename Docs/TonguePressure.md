# Язык под весом игроков и предметов

Язык слегка прогибается под стоящим зубом. У лежащего ragdoll область давления
шире; у еды глубина зависит от массы, а ширина — от размера коллизии. При
перетаскивании вмятина следует за предметом, прежнее место плавно выпрямляется.
После приземления давление на короткое время усиливается.

Вмятина от веса — **визуальный WPO**: материал смещает вершины при отрисовке.
Исходная сетка, её топология и высота физического пола от веса не меняются.
Это небольшое дополнение к существующим движениям языка. Волна боли,
локальный подъём и сильный рывок продолжают работать поверх вмятин.

## Как проверить

1. Запустить `L_Mouth`, встать на свободное место языка.
2. F3 → «Язык — сравнить вес 4 / 28 кг», закрыть панель.
3. Слева упадёт лёгкий предмет, справа — такой же тяжёлый. Потянуть через ЛКМ:
   под ним перемещается углубление, позади поверхность восстанавливается.
   Совместный хват добавляет силу; для первого знакомства удобнее лёгкий предмет.
4. Прыгнуть: в воздухе зуб не давит; после приземления прогиб кратковременно
   сильнее. Проверить ragdoll через соответствующую кнопку F3.
5. «Язык — включить / выключить продавливание» позволяет сравнить эффект.
   Отключение плавно убирает вмятины. Кнопки работают только у хоста.

Тестовые предметы создаются обычным `MCFoodActor`, поэтому используют настоящий
хват и физическую массу. Повторное сравнение заменяет только предыдущую пару.
Настройки ассета кнопками не сохраняются.

## Где настраивать

Открыть `/Game/Data/DA_Tongue`, категорию **Weight → Pressure**. Изменять при
остановленном Play; следующий запуск прочитает значения.

| Поле | Назначение |
| --- | --- |
| Enabled | Включение давления |
| Depth Per Kg | Чувствительность к массе, по умолчанию 0,4; 0 отключает новые вмятины |
| Max Depth | Верхний предел визуальной глубины, по умолчанию 8 см |
| Player Radius / Ragdoll Radius | Размер мягкой области под игроком / ragdoll |
| Food Margin | Дополнительная ширина вокруг физического габарита еды |
| Press Seconds | Время реакции на появившийся вес |
| Recover Seconds | Время плавного восстановления; больше — дольше сохраняется след |
| Landing Boost / Landing Speed | Усиление при приземлении и скорость для полного эффекта |
| Contact Tolerance | Небольшой допуск контакта физического тела с языком |
| Max Sources | Бюджет одновременных объектов, по умолчанию 24 |

Глубина плавно приближается к пределу, поэтому `масса × Depth Per Kg` не
равняется конечной вмятине. На краях прогиб ослаблен, чтобы не разрывать стык
со стенками рта. Скорости реакции задают экспоненциальное приближение: за одно
указанное время проходит примерно 63% изменения, а не мгновенное завершение.
Масса еды берётся из её игровых настроек / строки меню, масса игрока — из
профиля физики. Большой размер расширяет область давления без увеличения массы.

## Что создано и зачем

| Файл | Ответственность |
| --- | --- |
| `MCTonguePressure.h` | Настройки и небольшой сетевой список точек давления |
| `MCTonguePressure.cpp` | Поиск опоры, масса, приземление, плавные вмятины и восстановление |
| `MCTongue.cpp` | Физические движения событий; глубина веса в UV1 и пересчёт нормалей |
| `M_TonguePain` | Читает UV1 и применяет глубину веса через WPO |
| `MCTongueProfile.Pressure` | Настройка через существующий DA без нового менеджера событий |
| `MCDevCommands / MCDevPanelWidget` | Сравнение масс и выключатель в F3 |

Сервер проверяет контакт: стоящий персонаж должен иметь опору на языке,
ragdoll и еда — находиться возле поверхности без другой опоры между ними.
Поднятые, застрявшие и удалённые предметы не создают давление; плавающий или
зацепившийся игрок тоже. Несколько держащих игроков не умножают массу одного
предмета. После удаления объекта его старый след самостоятельно исчезает.

Клиенты получают точки давления до 10 раз в секунду и сглаживают их. Вершины
сетки по сети не передаются. CPU считает небольшое поле глубины и передаёт
его в UV1; материал применяет смещение на GPU. UV0 и материал художника
сохранены; изменён производный `M_TonguePain`. Нормали учитывают вмятины,
чтобы блики следовали форме. Это не симуляция мягкого тела.

Сильные движения событий по-прежнему изменяют геометрию и коллизию вместе.
Вес добавляет только видимое углубление поверх этой поверхности. Поэтому
глубина ограничена: слишком большое значение покажет зазор между ногами и
языком. Сброс дня очищает историю вмятин.

## Границы приближения

Один объект создаёт одну округлую область. У ragdoll проверяется основное
тело, а не давление каждого пальца. У еды используется габарит физического
коллайдера. Передача нагрузки через стопку предметов пока не рассчитывается.
При превышении бюджета сохраняются игроки, затем самые тяжёлые поддержанные
предметы. Для произвольных новых форм арены нужно снова проверить плотность
сетки и её закреплённые границы.

## Воспроизведение проверки

`Tools/Test.ps1 -Mode Unit` проверяет массу, контакт, прыжок/приземление,
ragdoll, удаление, восстановление и сброс.

`Tools/Test.ps1 -Mode TonguePressureNetwork -PacketLagMs 75 -PacketLoss 2`
запускает хоста и три клиента: сравнение масс, настоящий хват и перетаскивание,
отрыв предмета от земли, восстановление, совмещение с движением языка и
физические трассировки по центрам треугольников базовой игровой поверхности.
Модульная проверка отдельно подтверждает: в UV1 есть глубина, а физическая
высота от веса не меняется.

`Tools/CaptureTongue.ps1 -Pressure` записывает тот же сценарий в
`Artifacts/TonguePressure.mp4`. Интервалы снимков сохраняются; ролик
демонстрирует механику, но не измеряет FPS обычного Play. Качество рендера
снижено только для тестовой записи; настройки проекта не меняются.

[Запись из Unreal](../Artifacts/TonguePressure.mp4): сначала два веса и ragdoll,
с 6-й секунды лёгкий предмет поднят для проверки исчезновения опоры; затем
два игрока тянут тяжёлый. С 14-й секунды поверх вмятин запускается локальное
движение языка, с 19-й давление выключено и сброшено. Подвешенный предмет —
тестовый приём проверки контакта, отдельной игровой способности левитации нет.
