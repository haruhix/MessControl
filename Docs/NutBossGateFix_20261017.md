# Ореховый катаклизм: обязательный переход к боссу

На сохранённой `L_Mouth` воспроизведён обычный запуск через F3: после дождя все шесть оставшихся орехов были `Free`, но к 23-й секунде событие стало `Complete`, `bFailed=true`, боссов — 0. Причина — единственный вызов случайного размещения выбирал недоступную полосу языка и сразу отменял бой.

Изменения:

- Рыцарь получает запасную точку из мест падения орехов с повторной проверкой полного габарита на текущей поверхности. Если прежние места больше не подходят, ограниченный поиск проверяет обе разрешённые полосы. Ограничения краёв, приёмников и доступности игрокам сохраняются.
- Стадия боя начинается после фактического создания единственного рыцаря с последующей формой колдуна. Неудача размещения теперь имеет отдельный диагностический лог.
- Переход ждёт активные полёты; скатившиеся и подпрыгивающие остатки не отменяют босса. Зависший полёт удаляется по ограниченному таймауту, после чего бой продолжается. Остальные орехи сохраняются для призыва колдуна.

Проверки и исходное воспроизведение сохраняются в `Artifacts/NutBossGateFix_20261017`. Обе регрессии прошли: недоступная случайная полоса, остаток вне языка, зависший активный полёт. Обычная solo-проверка через F3 прошла все пять проверок: шесть орехов, единственный рыцарь появился примерно на 23-й секунде через запасную точку (`placement_fallback=1`), завершил падение и сохранил бой открытым после таймера дождя. Таймеры дождя/появления не менялись; HP наблюдателя восстанавливалось. Сборка модуля редактора выполнена успешно; временные настройки частоты кадров восстановлены.

Отдельная сборка Windows/cook/package в рамках исправления не запускалась.
