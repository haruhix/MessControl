# Dev-панель механик

В Play нажми **F3**. Закрыть — **F3**, **Esc** или кнопка внизу. F1 по-прежнему открывает лабораторию анимации и физики, F2 — подключение друзей. Эти панели не перекрывают друг друга.

Dev-панель доступна в Editor и Development. В кооперативе события запускает **хост listen-сервера**; клиенты видят панель с отключёнными кнопками и получают обычные реплицируемые результаты. В Shipping команды запрещены. Управление выделенным сервером пока не предусмотрено.

## С чего начать

1. Нажми F3 и выбери `BREAKFAST IS FALLING`: начнётся чистый тест завтрака.
2. Закрой панель. Еда поступит из `DT_BreakfastMenu` за заданное в DA время; её можно разбивать, хватать и тащить. После окончания дождя тест останется на этом этапе.
3. Открой F3 и нажми **Инфекция**: перед персонажем появится кусок с ускоренной порчей. Под ним возникнет настоящая язва. Убери еду и защищай язву до заживления.
4. Для воды выбери `COFFEE / SURVIVE FOUR WAVES`, закрой панель и проверяй подгребание и зацеп. Для налёта можно добавить **Кофейный налёт + щётки**.
5. **Обычный день 1 — полный перезапуск** возвращает обычную последовательность с обучением и таймерами.

## Два вида кнопок

**Этапы дня слева — чистый запуск.** Кнопка сбрасывает текущий день для всех участников: пересоздаёт игроков, восстанавливает все игровые зубы с карты и здоровье рта, убирает еду, пятна, язвы и воду. Затем запускается только выбранный этап. Для прямого запуска уборки завтрака создаётся еда, для выбрасывания щёток — щётки; проходить предыдущий этап не нужно.

На текущей `L_Mouth` после коммита блокинга `99cf8c0` сохранены только два маркера `MCArenaToothSocket` (01 и 02), хотя правила требуют восемь. Остальная видимая геометрия сама по себе игровым зубом не становится. Панель показывает реальное число и сообщение о недостающих местах. Карта этой доработкой не изменяется; для полного запаса нужно вернуть шесть маркеров и расположить их по новой арене.

Список читается из `Steps` у `DA_Day01`, назначенного в `MCGameMode.FirstDayPlan`. Названия и подсказки берутся из тех же данных. Новый элемент с уже поддержанным типом события появится при следующем открытии панели. Совсем новая механика всё равно требует реализации в директоре дня. Завершение дня не показывается как отдельное игровое событие.

**Действия справа — добавить к текущему состоянию.** Они не очищают сцену и отключают дальнейшие автоматические переходы, чтобы сочетать эффекты:

| Действие | Что проверяет |
| --- | --- |
| Еда перед игроком | Случайный целый кусок из меню, падение, урон, разрушение и хват |
| Инфекция | Один новый кусок быстро портится через обычную систему порчи и создаёт язву на поверхности |
| Кофейный налёт + щётки | Большие зубы, игроки, поверхность; контакты щёткой и совместная чистка |
| Щётки с неба | Подбор E и выброс Q за передний край |
| Расшатать зубы и игроков | Уход E, самопомощь C + E |
| Урон −25 HP | Материал повреждения, реакция персонажа и лечение |
| Толчок / ragdoll | Обычный физический удар и восстановление после падения |
| Гибель → возрождение | Гибель игрока хоста и расход конкретного большого зуба |
| Здоровье рта | Восстановление только общего HP, без удаления язв |
| Слить кофе | Остановка воды и освобождение зацепов; грязь остаётся |

Место появления еды ищется перед хостом трассировкой пола. Если пола нет, панель сообщает об этом. Для инфекции ускоряется только срок порчи нового куска — значения таблицы не меняются. Одновременный лимит язв остаётся штатным: 24.

## Что означает ручной режим

Нет штрафа за истечение таймера и автоматического перехода к следующему этапу. **Физика, урон, порча еды, заживление язв и расход зубов на возрождение продолжаются.** Проиграть из-за здоровья или отсутствия зубов всё ещё можно; после этого выбери чистый запуск этапа.

Внутренний ритм событий сохраняется: дождь еды занимает свои две секунды, кофейные волны — свои десять (или значения из DA). Панель не делает воду бесконечной. По завершении волны вода уходит, а тест ждёт твоей команды. В HUD видна отметка `DEV TEST`, в панели — здоровье, количество еды/язв/зубов и наличие воды.

Открытая панель **не останавливает мир**. Она прекращает текущий хват/чистку и блокирует управление своим персонажем, чтобы клики по кнопкам не наносили удары. Для проверки взаимодействий её нужно закрыть. Настройки ассетов и карта не сохраняются и не изменяются этими командами.

Зевание, тряска локации и пенная вечеринка ещё не реализованы; кнопок, имитирующих их работу, нет.

## Где находится логика

| Файл | Зачем нужен |
| --- | --- |
| `MCDevPanelWidget` | Окно, список этапов из DA, кнопки, подсказки и текущие показатели |
| `MCDevCommands` | Типы команд и их выполнение в GameMode; проверка доступа хоста |
| `MCPlayerController` | F3, переключение ввода, сохранение панели при возрождении |
| `MCDayDirector` | Запуск указанного этапа и отключение автоматических переходов в ручном режиме |
| `MCGameState.bDevManualEvents` | Репликация ручного режима и правильная подпись HUD у всех игроков |

Команды обращаются к обычным `DayDirector`, `FoodActor`, статусам и физическому компоненту. Отдельных копий кофе, инфекции или системы возрождения для панели нет.

Проверки: `Tools/Test.ps1 -Mode Unit` и `Tools/Test.ps1 -Mode DevPanelNetwork -PacketLagMs 75 -PacketLoss 2 -CaptureDevPanel`. Сетевая проверка запускает хоста и три клиента, проверяет события и запрет управления для клиента; флаг записи сохраняет скриншот в `Artifacts/DevPanel.png`.
