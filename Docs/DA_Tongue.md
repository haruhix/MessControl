# DA_Tongue: где настраивать язык

## Быстро: изменить глубину продавливания

1. В Content Browser открыть `Content/Data/DA_Tongue` (`/Game/Data/DA_Tongue`).
2. В разделе **Weight** посмотреть **Default Pressure Preset**. В проекте
   назначен `/Game/Data/Pressure/DA_Pressure_Soft` — «Мягкий».
3. Открыть назначенный пресет и раскрыть **Preset → Settings → Pressure**:
   - **Max Depth** — предел глубины в сантиметрах, допустимо **1–35 см**.
   - **Depth Per Kg** — насколько сильно масса продавливает язык, допустимо **0–3**.
4. Для усиления только следа игрока открыть **Settings → Weight Scales**
   и увеличить **Player Depth Scale**. Еда и ragdoll имеют отдельные множители.
5. Сохранить ассет и запустить Play. В уже запущенном PIE применить параметры
   через F3 → **«Давление — Мягкий»** или **«Давление — применить DA_Tongue»**.

**Когда `Default Pressure Preset` заполнен, встроенные настройки
`DA_Tongue → Weight → Pressure` не используются.** Для настройки прямо в
`DA_Tongue` очистить эту ссылку (`None`), затем менять **Weight → Pressure**.
Вложенные группы и поля в обоих вариантах одинаковые.

`Max Depth` ограничивает глубину, но не задаёт её каждому следу. Чтобы углубить
слабый след, увеличивать `Depth Per Kg` или множитель нужного типа нагрузки.
Для выключения продавливания снять `Enabled`; нулевой `Max Depth` не поддерживается.

## Как связаны ассеты

На карте `L_Mouth` выбрать актор **GAMEPLAY | Moving tongue**.
Его **Tongue → Profile** указывает на `DA_Tongue`.

| Где | Что настраивается |
| --- | --- |
| `DA_Tongue → Tongue → Settings → Idle` | Фоновое покачивание |
| `DA_Tongue → Tongue → Settings → Jolt` | Включение и интервалы автоматических рывков |
| `DA_Tongue → Weight → Default Pressure Preset` | Пресет продавливания при запуске |
| `DA_Tongue → Weight → Pressure` | Продавливание при пустом `Default Pressure Preset` |
| `DA_Tongue → Weight → Pressure Presets` | Список вариантов для сравнения через F3 |
| `DA_Tongue → Events → Pain Motion / Jolt Motion` | Профили волны боли и сильного рывка |
| `DA_Tongue → Events → Dev Motions` | Дополнительные движения в F3 |
| Назначенный пресет → `Appearance → Surface Material` | Материал поверхности при выборе этого пресета |

Переключение пресета в F3 действует в текущей игре. Чтобы выбрать его для
следующих запусков, назначить `Default Pressure Preset` и сохранить `DA_Tongue`.
Для своего варианта дублировать DA пресета и его Material Instance, связать копии
через `Surface Material`, добавить DA в `Pressure Presets`. После изменения
списка закрыть и заново открыть F3.

## Все параметры продавливания

Путь: **назначенный пресет → Preset → Settings** или, при пустой ссылке на
пресет, **DA_Tongue → Weight → Pressure**. Ниже указаны допустимые диапазоны
из кода; это не текущие значения ассетов. Длины — в см, время — в секундах.
При применении значения ограничиваются этими диапазонами.

### Глубина и чувствительность

| Группа / поле | Диапазон | Эффект |
| --- | --- | --- |
| Pressure / `Enabled` | Вкл. / выкл. | Разрешает продавливание. После отключения следы плавно исчезают |
| Pressure / `Depth Per Kg` | 0–3 | Чувствительность к массе для всех нагрузок. 0 прекращает создание новых вмятин |
| Pressure / `Max Depth` | 1–35 см | Предел глубины, в том числе при наложении нескольких нагрузок |
| Pressure / `Falloff Power` | 2–6 | 2 — широкая чаша; 6 — узкий центр с плавным краем |
| Weight Scales / `Player Depth Scale` | 0–3 | Множитель давления стоящего или идущего игрока |
| Weight Scales / `Ragdoll Depth Scale` | 0–3 | Множитель давления упавшего игрока |
| Weight Scales / `Food Depth Scale` | 0–3 | Множитель давления еды |

Множитель 0 отключает вклад соответствующего типа нагрузки. Масса игрока
берётся из его настроек физики, масса еды — из её игровых настроек.

Для одной неподвижной нагрузки в центре вмятины, без усиления приземления
и ослабления у границ, расчёт можно представить так:

```text
Нагрузка = масса (не более 200 кг) × Depth Per Kg × Depth Scale
Глубина = Max Depth × Нагрузка / (Max Depth + Нагрузка)
```

Например, при массе 28 кг, `Depth Per Kg = 0.8`, `Food Depth Scale = 1`
и `Max Depth = 18` получается около **10 см**, а не 18 см. Реальная поверхность
приближается к этому значению постепенно; у закреплённых краёв и на нижней
части языка деформация слабее. Покачивание и движения событий добавляются
к продавливанию, поэтому `Max Depth` не ограничивает полное движение языка.

### Размер и форма следа — Footprint

| Поле | Диапазон | Эффект |
| --- | --- | --- |
| `Player Radius` | 60–250 см | Продольный радиус области под стоящим / идущим игроком |
| `Ragdoll Radius` | 60–300 см | Продольный радиус области под ragdoll |
| `Player Width Ratio` | 0.5–1.5 | Поперечная ширина относительно `Player Radius`; 1 — круг |
| `Ragdoll Width Ratio` | 0.5–1.5 | Поперечная ширина относительно `Ragdoll Radius` |
| `Food Margin` | 30–120 см | Добавка к половине размера коллизии еды по каждой горизонтальной оси |

Итоговые радиусы нагрузок дополнительно ограничены 60–300 см. Увеличение
радиуса расширяет след; масса при этом сохраняется.

### Скорость продавливания и восстановления — Timing

| Поле | Диапазон | Эффект |
| --- | --- | --- |
| `Press Seconds` | 0.06–1 с | Чем меньше, тем быстрее поверхность реагирует на вес |
| `Recover Seconds` | 0.15–5 с | Чем больше, тем медленнее выпрямляется след |
| `Trail Hold Seconds` | 0–1 с | Пауза перед восстановлением после уменьшения нагрузки; 0 — начать сразу |

`Press Seconds` и `Recover Seconds` — время прохождения примерно **63%**
изменения. После паузы след восстанавливается примерно на 95% за
`3 × Recover Seconds`, а не исчезает полностью за один этот интервал.

### Приземление, контакт и число нагрузок

| Группа / поле | Диапазон | Эффект |
| --- | --- | --- |
| Landing / `Landing Boost` | 0–2 | Дополнительное давление от удара; 0 отключает усиление |
| Landing / `Landing Speed` | 100–1200 см/с | Скорость падения для полного усиления; меньше — сильнее реакция на небольшой прыжок |
| Landing / `Landing Seconds` | 0.08–1 с | Время затухания добавочного давления |
| Contact / `Contact Tolerance` | 3–20 см | Допуск контакта еды и ragdoll с поверхностью |
| Budget / `Max Sources` | 4–32 | Максимум одновременно учитываемых нагрузок; приоритет у игроков, затем у еды с большим вкладом |

В воздухе игрок не продавливает язык. Еда должна опираться на него:
предметы на другой опоре, экипированные и застрявшие предметы не создают нагрузку.

## Цвет и влажность вмятины

Для стартового пресета открыть
`/Game/Gameplay/Arena/Pressure/MI_Pressure_Soft`, группу **Pressure | Appearance**.
Если выбран другой пресет, открыть материал из его `Surface Material`.

| Параметр | Для чего менять |
| --- | --- |
| `Pressure Contrast` | Значение меньше 1 делает слабое давление заметнее |
| `Pressure Feather` | Больше — мягче исчезает край; меньше — заметнее мелкие остаточные следы |
| `Pressure Tint` / `Pressure Tint Amount` | Цветовой множитель и сила оттенка; Tint выше 1 осветляет ткань |
| `Pressure Darken` | Затемнение вмятины |
| `Pressure Wetness` / `Pressure Roughness` | Сила влажного эффекта и шероховатость |
| `Pressure Rim Light` | Осветление наклонного края |
| `Pressure Normal Flatten` | Сглаживание мелкого рельефа во вмятине |

Геометрическая глубина задаётся в DA и одновременно меняет видимую поверхность
и коллизию. Старый параметр материала `Heiht` удалён; отдельной глубины через
World Position Offset (WPO) у продавливания нет. Если `Surface Material` пуст,
используется обычный материал актора языка.

## Покачивание и сильные движения

В **DA_Tongue → Tongue → Settings**:

| Группа / поле | Что меняет |
| --- | --- |
| Idle / `Idle Height` | Амплитуда фонового покачивания, 0–8 см; 0 отключает его |
| Idle / `Idle Period` | Период покачивания, 2–30 с |
| Jolt / `Automatic Jolts` | Автоматические сильные рывки; выключены в сохранённом DA и native defaults |
| Jolt / `Jolt Rest Min` | Минимальная случайная пауза, 8–180 с |
| Jolt / `Jolt Rest Max` | Максимальная пауза, не меньше Min и не больше 240 с |

В ручном режиме событий F3 автоматические рывки отключены. Кнопка ручного
рывка продолжает работать. Для изменения этих настроек перезапустить Play:
**«Давление — применить DA_Tongue» перечитывает только продавливание.**

Высоту и силу событий менять в профилях, назначенных в **Events**:
`/Game/Data/DA_Tongue_Pain` и `/Game/Data/DA_Tongue_Jolt`, раздел **Motion → Settings**.
Дополнительные примеры — `DA_Tongue_LocalLift` и `DA_Tongue_Travel`.

| Группа / поля | Что меняют |
| --- | --- |
| Shape / `Shape` | `FrontBend` — изгиб передней части; `RadialWave` — волна от точки; `LocalLift` — локальный подъём; `DirectionalWave` — направленная волна |
| Shape / `Height`, `Radius` | Высота и область события. У `FrontBend` область задана формой языка, `Radius` её не меняет |
| Wave / `Width`, `Speed` | Ширина и скорость фронта волны |
| Timing / `Anticipation` | Задержка перед основным движением |
| Timing / `Rise`, `Hold`, `Return` | Подъём, удержание и возврат для `FrontBend` и `LocalLift`; длительность волн определяется радиусом, шириной и скоростью |
| Timing / `Rest After` | Пауза после движения до разрешения следующего |
| Animation / `Compression`, `Follow Through` | Поджатие перед подъёмом и небольшое движение после возврата для `FrontBend` и `LocalLift` |
| Color / `Redness` | Выраженность красного градиента |
| Force / `Lift`, `Push` | Вертикальный и горизонтальный толчок объектов |
| Force / `Affect Height` | Допустимая высота объектов над языком для действия толчка |
| Force / `Push From Origin` | Толчок от центра события; при выключении используется направление события |
| Force / `Food Lift Ignores Mass` | Вертикальный подброс еды без ослабления её массой |

Параметры профиля копируются при запуске события: для проверки правки запустить
его заново после окончания предыдущего движения и `Rest After`.
Поля `Jolt Height`, `Jolt Lift`, `Wave Height`, `Push Speed` и остальные
старые настройки события внутри `DA_Tongue.Settings` действуют только при
пустой соответствующей ссылке `Jolt Motion` / `Pain Motion`.

## Проверка и частые вопросы

1. Запустить `L_Mouth` как хост и открыть F3. Строка **«Давление: …»** показывает
   реально выбранный пресет, предел глубины и время восстановления.
2. Применить нужный пресет и нажать **«Язык — сравнить вес 4 / 28 кг»**.
   Закрыть F3, сравнить прогиб и перетащить предмет через ЛКМ.
3. Пройти и прыгнуть по центральной части языка, проверить след игрока и удар
   при приземлении. Для повторного опыта использовать **«Давление — очистить следы»**;
   оставшиеся на поверхности объекты сразу начнут создавать новые вмятины.

| Наблюдение | Что проверить |
| --- | --- |
| Изменил `DA_Tongue.Pressure`, ничего не произошло | `Default Pressure Preset`: при назначенной ссылке редактировать её пресет |
| Изменил пресет во время Play, эффект прежний | Повторно нажать его кнопку в F3; для стартового выбора — «Давление — применить DA_Tongue» |
| Увеличил `Max Depth`, но след всё ещё неглубокий | Поднять `Depth Per Kg` или нужный `Depth Scale`; проверить вдали от закреплённого края |
| Хочется более широкий след | Увеличить радиус / `Food Margin`, уменьшить `Falloff Power` |
| След слишком быстро пропадает | Увеличить `Recover Seconds` и при необходимости `Trail Hold Seconds` |
| Физический прогиб есть, но его плохо видно | Проверить материал пресета, `Pressure Contrast`, оттенок и влажность |
| После перезапуска выбран другой пресет | Сохранить нужную ссылку в `Default Pressure Preset`; выбор F3 временный |
| Не получается применить настройку у клиента | Команды F3 выполняет хост; результат передаётся клиентам |
