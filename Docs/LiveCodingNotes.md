# Live Coding в UE 5.8.1

Во время интеграции полигона Live Coding повторно выполнял 62 compile-actions даже после изменения только четырёх `.cpp`, без изменений заголовков. Последние два прогона компилятора заняли 672 и 549 секунд.

Вероятная причина по текущим исходникам UBT и реальным response-файлам: обычные и Live Coding compile-actions используют один `<cpp>.sarif` как produced output, хотя LC меняет команду на `.lc.rsp` и отдельные object/dependency outputs. Обновление producing attributes в ActionGraph может попеременно инвалидировать этот общий файл. Причина не подтверждена отдельным инструментальным экспериментом.

Для дальнейшей работы локальный `Saved/UnrealBuildTool/BuildConfiguration.xml` возвращается к настройке только SARIF:

```xml
<Configuration xmlns="https://www.unrealengine.com/BuildConfiguration">
  <WindowsPlatform>
    <bWriteSarif>false</bWriteSarif>
  </WindowsPlatform>
</Configuration>
```

`bWriteSarif` — поддерживаемая настройка WindowsPlatform в UBT 5.8, отключающая дополнительные SARIF-файлы. Обычные ошибки и предупреждения компилятора остаются. Настройка находится в игнорируемой папке Saved и действует только в этом checkout. Глобальные пользовательские настройки и исходники движка не изменены. Исходный локальный XML сохранён в `Saved/Codex/BuildConfiguration.before-vfx-lab.xml`; состояние с отключённым SARIF перед временным отключением PCH — в `Saved/Codex/BuildConfiguration.before-no-pch.xml`.

Изменение compiler arguments может вызвать полный rebuild. Подтверждённого ускорения последующих итераций нет; отдельную сборку ради измерения не запускали.

Первая интеграция после отключения SARIF пересобрала общие заголовки и выполнила 70 действий за 655,23 секунды. Компиляция и создание патчей игровых и редакторских модулей завершились успешно.

При следующем холодном запуске редактора UBT выполнил 70 действий за 313,07 секунды и сообщил об успешной компиляции. Затем Live Coding не смог слинковать патч: `LNK2011` указал на отсутствующий объект precompiled header. Успешный результат UBT в этом случае не означает успешную интеграцию патча в редактор.

Попытка восстановления отдельно создала обычный PCH за 98,51 секунды. Подход с обновлением времени файла снова поставил в очередь 70 действий, включая PCH; этот процесс UBT был отменён.

Для следующей попытки временно установили `bUsePCHFiles=false`. В трёх ModuleRules временно добавили `ForceIncludeFiles` для `UnrealEdSharedPCH.h`: заголовок разбирался как обычный include, закрывая существующие зависимости на содержимое PCH. Эти незакоммиченные изменения правил модулей восстановлены после проверки.

69 действий без PCH завершились успешно за 1060,02 секунды. При применении патча Live Coding редактор аварийно завершился на инициализации статистики Chaos `ParticleIterator`, до запуска игрового сценария.

Для восстановления использовали уже скомпилированные объекты и перенесли созданные `.lc.dep` в обычные `.dep`. Холодный нативный запуск `Build.bat` выполнил семь действий линковки и обновления метаданных за 7,76 секунды и завершился успешно. После этого редактор успешно открыл полигон `L_VFXLab`.

Перед публикацией локальный XML восстанавливается из `Saved/Codex/BuildConfiguration.before-no-pch.xml`, оставляя только `bWriteSarif=false`. Для следующих попыток Live Coding нужна обычная нативная сборка с PCH, создающая согласованную исходную базу объектов и заголовков. Компиляция без PCH и восстановление линковки не подтверждают ускорение Live Coding.

F3-панель затем интегрирована с закрытым редактором: итоговые четыре действия заняли 53,67 секунды. Коррекция масштаба этой панели потребовала ещё четырёх действий за 56,39 секунды. Обе интеграции завершились успешно; временные правила трёх модулей и локальный XML восстановлены. Новый редактор запущен с актуальными нативными DLL, панель проверена в клиентском PIE и большом окне редактора.

Проверенные источники движка: `Platform/Windows/UEBuildWindows.cs` (`bWriteSarif`), `Platform/Windows/VCToolChain.cs` (SARIF outputs), `Configuration/Xml/XmlConfig.cs` (project Saved XML), `System/ActionGraph.cs` (producing attributes / outdated actions).
