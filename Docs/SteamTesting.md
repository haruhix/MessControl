# Тест с другом через Steam / Spacewar

Сборка использует тестовый Steam App ID 480. Steam показывает MessControl как
Spacewar. Нужны два компьютера, разные аккаунты Steam и одинаковая сборка игры.

1. Передай другу всю папку `Windows` или ZIP с этой папкой. Распакуйте архив.
2. Оба запустите Steam и войдите в свои аккаунты в онлайн-режиме.
3. Оба запустите `Start_Steam.cmd` из папки игры.
4. Хост: F2 → **Создать комнату**. После загрузки карты комната доступна.
5. Друг: F2 → **Найти комнаты** → выбрать имя Steam хоста → **Подключиться**.
6. Можно также открыть F2 → **Пригласить друга в Steam** у хоста. Друг принимает
   приглашение в оверлее Steam (Shift+Tab), когда его игра уже запущена.

До четырёх игроков. Хост должен оставаться в игре. Для новой комнаты или после
разрыва соединения снова открой F2. Поиск показывает только комнаты MessControl
с совместимым идентификатором сборки, поскольку App ID 480 общий для тестов.
Steam Sockets передаёт игровой трафик через Steam P2P/relay; вручную вводить IP
для этого режима не нужно.

Если F2 показывает поле IP вместо кнопок Steam, закрой игру, проверь вход в Steam
и запусти `Start_Steam.cmd` ещё раз. Скрипт восстанавливает `steam_appid.txt`,
который движок может удалить при выходе. При пустом списке хост сначала создаёт
комнату, затем друг повторяет поиск. Приглашение доступно после создания комнаты.
Проверьте, что у обоих одна версия игры. Поиск Steam ограничен близкими регионами,
определяемыми по IP. Если друг далеко и комната не находится, используйте приглашение
через Steam при уже запущенной игре.

## Сборка и проверки для разработчика

Закрой редактор после сохранения ассетов:

```powershell
.\Tools\PackageWindows.ps1 -SteamTest
```

Сборка размещается в `Saved/Builds/Win64_<дата>/Windows`. Для локальной проверки
двух окон на одном ПК используй `Tools/PlayCoop.ps1`: она запускает прямой IP
с `-nosteam`, поскольку один аккаунт Steam не заменяет два разных клиента.
PIE в редакторе также использует локальный режим.

Development-сборка поддерживает последовательные проверки реального Steam:

```powershell
.\Tools\TestSteamBuild.ps1 -BuildRoot 'D:\путь\к\сборке\Windows'
```

Первая проверяет создание лобби и запуск SteamSocketsNetDriver, вторая —
завершение поиска лобби с фильтром MessControl. Маркер успеха в логе:
`MC_STEAM_TEST_PASS`. Эти проверки на одном аккаунте не проверяют соединение
между двумя пользователями; его проверяют шагами выше на двух ПК.

App ID 480 предназначен для тестирования. Перед публикацией игры замени его
своим App ID и настрой Steamworks. При упаковке публичной версии не добавляй
тестовые `steam_appid.txt` и `Start_Steam.cmd`.
