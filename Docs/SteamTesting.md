# Тест с другом через Steam / Spacewar

Сборка использует тестовый Steam App ID 480, поэтому Steam показывает её как
Spacewar. Это общий тестовый App ID, собственного App ID у этой сборки нет.
Для игры вдвоём нужны два компьютера, разные аккаунты Steam и одинаковая версия
архива. Хост должен оставаться в игре; команда — до четырёх игроков.

1. Передай другу всю папку `Windows` или ZIP с этой папкой. Распакуйте архив.
2. Оба запустите Steam и войдите в свои аккаунты в онлайн-режиме.
3. Оба запустите `Start_Steam.cmd` из папки игры.
4. Хост: в главном меню нажми **Играть / Play** и дождись загрузки хаба.
   При работающем Steam создаётся комната с режимом **Только друзья**.
5. В хабе нажми **Tab** → **Пригласить друзей**. Откроется интерфейс приглашений
   Steam. Друг принимает приглашение через **Shift+Tab**, когда его игра уже
   запущена. Приглашения доступны во время сбора команды в хабе.
6. После подключения всей командой встаньте в подсвеченную **READY-зону**.
   Хост нажимает **Enter**, выбирает доступный день и снова **Enter**, чтобы
   начать игру. Сбор команды происходит в самом хабе.

**Tab** в хабе открывает и закрывает панель команды: список игроков, приглашения
и режим доступа. Хост может выбрать **Открытая**, **Только друзья** или
**По приглашению**; дождись подтверждения изменения в панели. **Esc** закрывает
открытую панель, а из обычной игры открывает меню с настройками и выходом.
Приглашение также доступно в меню **Esc** в хабе. **Shift+Tab** открывает оверлей Steam.

Для подключения через список открой в главном меню **Играть с друзьями /
Join friends** → **Найти комнаты / Find Steam Lobbies**, выбери имя хоста и
нажми **Подключиться / Join Selected Lobby**. Комната «По приглашению» не
публикуется в поиске: для неё используй приглашение Steam. Поиск отбирает комнаты
с идентификатором MessControl и свободными местами; одинаковый архив всё равно
нужен, чтобы у игроков совпадали код и ассеты.

Кнопка **Играть** сейчас создаёт свой хаб. Автоматический Quick Play с поиском
свободной комнаты и созданием новой при отсутствии результатов ещё не подключён.
Отдельной страницы **Host Private Game** нет: доступ меняется через **Tab** в хабе.
Для новой комнаты выйди в главное меню через **Esc** и снова нажми **Играть**.
Steam Sockets использует Steam P2P/relay; в этом режиме вводить IP не требуется.

Ники игроков отображаются над головами и берутся из сетевого `PlayerState`.
При подключении через Steam используется имя профиля; в локальном режиме —
имя игрока Unreal. Подпись сохраняется после возрождения. Высоту можно изменить
в компоненте персонажа **PlayerName → Height Above Head**.

Если кнопки Steam скрыты или хаб обозначен как локальный, закрой игру, проверь
вход в Steam и запусти `Start_Steam.cmd` ещё раз. Скрипт восстанавливает
`steam_appid.txt`, который движок может удалить при выходе. При пустом списке
убедись, что хост уже загрузил хаб, есть свободные места и доступ не установлен
«По приглашению», затем повтори поиск. Если комната не находится, попробуй
приглашение через Steam при уже запущенной игре. Проверьте одинаковую версию игры.

## Сборка и проверки для разработчика

Закрой редактор после сохранения ассетов:

```powershell
.\Tools\PackageWindows.ps1 -EngineRoot 'E:\UE\UE_5.8' -SteamTest
```

Сборка размещается в `Saved/Builds/Win64_<дата>/Windows`. Для локальной проверки
двух окон на одном ПК используй `Tools/PlayCoop.ps1`: она запускает прямой IP
с `-nosteam`, поскольку один аккаунт Steam не заменяет два разных клиента.
PIE в редакторе также использует локальный режим.

Сетевую проверку подписей (включая кириллицу, смену имени и возрождение) запускает
`Tools/TestPlayerNames.ps1 -Capture`. Для упакованной игры передай `-BuildRoot`
с путём к папке `Windows`.

Development-сборка поддерживает отдельные последовательные проверки реального
Steam. Они создают и ищут сетевые комнаты; запускай их только при согласованной
сетевой проверке:

```powershell
.\Tools\TestSteamBuild.ps1 -BuildRoot 'E:\путь\к\сборке\Windows'
```

Первая проверяет создание лобби и запуск SteamSocketsNetDriver, вторая —
завершение поиска лобби с фильтром MessControl. Маркер успеха в логе:
`MC_STEAM_TEST_PASS`. Эти проверки на одном аккаунте не проверяют соединение
между двумя пользователями; его проверяют шагами выше на двух ПК. Обычный запуск
с маркером `MC_STEAM_READY` подтверждает доступность Steam-аккаунта для игры,
но не создание комнаты и не подключение другого игрока.

Для диагностических запусков задавай отдельный `-UserDir=E:/CodexWork/<проверка>/UserData`
и process-scoped `TEMP`/`TMP` на E:, чтобы файлы проверки не попали на C: и не
затронули обычный профиль. Эта инструкция описывает доступные действия; результаты
конкретной сборки фиксируются отдельно и не следуют из наличия этих скриптов.

App ID 480 предназначен для тестирования. Перед публикацией игры замени его
своим App ID и настрой Steamworks. При упаковке публичной версии не добавляй
тестовые `steam_appid.txt` и `Start_Steam.cmd`.
