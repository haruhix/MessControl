# Кофе: поверхность и плавание ragdoll

Открой Play → **F3 → COFFEE / SURVIVE FOUR WAVES**, затем закрой F3. Подгребай **WASD / стиком**; удерживай **E возле большого игрового зуба**, чтобы зацепиться. После ухода воды персонаж сможет подняться обычным способом. Кнопка **Остановить кофе / слить жидкость** в F3 позволяет проверить это сразу.

## Что изменилось

Поверхность получила настоящую форму небольших волн, движущиеся блики, коричневый оттенок по видимой глубине, мягкие пересечения с ареной, пену/крема и кольца вокруг четырёх игроков. Мелкая рябь меняет нормали, более крупная — положение вершин. Это одна сетка из 6144 треугольников без коллизии; симуляции частиц жидкости нет.

Физика и материал используют одинаковые длину, амплитуду и скорость крупных волн. Сервер считает плавучесть относительно их высоты. Клиенты рисуют поверхность по синхронизированному времени сервера, чтобы высота не прыгала между сетевыми обновлениями.

Игрок остаётся **физическим ragdoll**: течение и подгребание прикладывают силы, суставы продолжают болтаться. Плавучесть удерживает корпус около поверхности, сопротивление ограничивает разгон. Это управляемое барахтанье, а не отдельная анимация плавания. Зацеп удерживает персонажа возле зуба; IK кистей пока нет. В воде вставание запрещено, после слива работает обычный поиск безопасного места для подъёма.

Еда тоже получает плавучесть и сопротивление. Масса учитывается при приложении силы. Полноценной гидродинамики каждого фрагмента и расчёта вытесненного объёма нет.

## Где настраивать

**`Content/Data/DA_Day01` → Coffee** задаёт событие: `Wave Count`, `Flood Height`, течение `Flow Acceleration`, силу подгребания `Paddle Acceleration`, дальность зацепа `Anchor Reach`. Длительность берётся из этапа `CoffeeWaves`. В обычном дне остаются четыре волны за десять секунд. `Coffee Profile` ссылается на новый профиль воды.

**`Content/Data/DA_CoffeeWater`** связывает поверхность, материал и настройки:

| Параметр | Для чего |
| --- | --- |
| `Ripple Height` | Амплитуда крупных волн, см; влияет на изображение и плавучесть |
| `Ripple Length` / `Ripple Speed` | Размер и скорость движения этих волн |
| `Float Depth` | На сколько сантиметров основная кость корпуса держится ниже поверхности |
| `Buoyancy Stiffness` | Сила возврата к высоте плавания |
| `Vertical Damping` | Гашение вертикальных скачков |
| `Water Drag` | Сопротивление горизонтальному движению; больше — медленнее плыть |
| `Surface Mesh` / `Surface Material` | Сетка и материал, которые можно заменить |

**`Content/Art/Materials/MI_CoffeeSurface`** — визуальные настройки без изменения кода:

| Параметр | Для чего |
| --- | --- |
| `Shallow Color` / `Deep Color` | Цвет мелкой и глубокой воды |
| `Shallow Opacity` / `Deep Opacity` | Прозрачность; уменьшай, если персонажей плохо видно |
| `Depth Tint Distance` | Дистанция перехода между оттенками по глубине изображения |
| `Foam Color` / `Foam Amount` | Цвет и количество кофейной пены |
| `Shore Foam Width` / `Edge Fade Distance` | Пена и смягчение пересечений с поверхностями |
| `Roughness` / `Specular` | Размер и выразительность бликов |
| `Normal Detail` | Мелкая рябь в освещении |
| `Refraction` | Слабое экранное преломление, близко к 1 |
| `Wake Strength` | Заметность колец вокруг игроков |
| `Ambient Fill` | Небольшая подсветка цвета для тёмной полости рта |

Параметры группы **Runtime** заполняются игровым актором каждый кадр. Амплитуду/скорость волн меняй в DA, а не в этой группе MI. Настройки профиля копируются сервером при запуске события; для проверки изменения перезапусти этап через F3.

## Границы решения

Материал использует прозрачность, экранную глубину и отражения. Оттенок и пена у пересечений зависят от камеры; это не симуляция объёма кофе. Волны не обходят препятствия и не стекают в глотку физически. Граница воды по-прежнему задаётся `Arena Half Size`, высота — относительно текущей арены. При замене уровня их нужно подогнать. Существующие карта и модели коллеги не перестраиваются.

Поверхность — критичный игровой ориентир. Для неё отключена задержка создания render proxy при подготовке PSO: при холодном запуске возможна пауза подготовки графики, но вода не должна скрываться во время действующего затопления. Предварительное кеширование PSO остаётся включено.

Кольца вокруг игроков — локальный визуальный эффект из реплицированных поз. Они не создают дополнительных сетевых сообщений и не меняют физические волны. Профилирование на целевой машине всё ещё нужно: у прозрачности и отражений есть GPU-стоимость, даже без fluid solver.

На текущем блокинге два игровых маркера зубов вместо восьми. Зацеп доступен у этих игровых зубов; обычная декоративная модель не становится точкой зацепа автоматически.

## Исходники и проверка

- `MCCoffeeProfile` — общие настройки волн, плавучести и сопротивления.
- `MCCoffeeFlood` — серверные силы, синхронная поверхность, передача параметров материала.
- `Tools/Blender/create_coffee_surface.py` и `ArtSource/CoffeeWater` — воспроизводимая сетка.
- `Tools/Unreal/create_coffee_water.py` — генератор новых материала, MI и DA. Существующие настройки MI/DA сохраняет; пересоздание мастер-материала требует явного `MC_REBUILD_COFFEE_WATER=1`.

`Tools/Test.ps1 -Mode Unit` включает тест реальных ragdoll-тел, плывущих в противоположные стороны. `Tools/CaptureCoffee.ps1` запускает четырёх участников с задержкой 75 мс и потерями 2%, проверяет плавание/зацеп/восстановление и записывает `Artifacts/CoffeeWater.mp4`. В демонстрации четыре волны растянуты до двадцати секунд для наглядности; значения DA не меняются.
