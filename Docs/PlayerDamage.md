# Повреждения эмали игрока

`M_TeethGameplay` использует параметр `Damage = 1 - Health / MaxHealth`.
Повреждения проявляются и исчезают при существующем изменении здоровья;
отдельный игровой статус не добавлен.

Визуальный слой повторяет характер референса: тонкая ветвящаяся сеть трещин,
более глубокие разломы от коронки и на корнях, светлый край эмали и затемнённое
углубление. Трёхмерная маска использует координаты до скиннинга и следует
за моделью. Нормаль учитывает углубление, сохраняя исходную normal map.
Крупные разломы лица ограничены передней стороной зуба. На спине используются
два самостоятельных коротких разлома с затухающими концами и меньшей шириной;
они не проецируют рисунок лица насквозь и не образуют замкнутые полосы.
Два небольших углубления коронки изменяют силуэт при сильном повреждении
через WPO и складываются с BodyStretch. Это косметический эффект материала;
коллизии и скелет сохраняют исходную форму.

Глаза и рот защищены по координатам исходной позы CharacterCurrent.
Цвет эмали ограничивает нанесение на тёмные детали лица и синий костюм.
Грязь Coffee и короткая вспышка HitFlash продолжают накладываться.

Настройки материала, группа **Enamel damage**:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| DamageCellSize | 22 | Размер ячеек сети трещин, см |
| DamageHairlineWidth | 1 | Множитель ширины тонких трещин |
| DamageMajorWidth | 1.05 | Ширина крупных разломов, см |
| DamageRelief | 1 | Сила углубления через нормаль |
| DamageChipDepth | 2.8 | Максимальная глубина углублений коронки, см |
| DamageHairlineColor | (0.27, 0.24, 0.20) | Тёплый серый тон тонких трещин |
| DamageDeepColor | (0.075, 0.065, 0.052) | Тёмная глубина разлома |

Цвета указаны в линейном пространстве. Авторинг:
`Tools/Unreal/build_player_fractures.py` через Python редактора при
остановленном PIE. Маска хранится в `player_fracture_mask.hlsl` рядом
со скриптом и записывается в Custom node материала. Повторное применение
маски грязи сохраняет входы слоя повреждений и его выходы.
