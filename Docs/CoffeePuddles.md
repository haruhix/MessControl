# Кофейные лужицы

Пятна на языке используют `MCMouthSurface.CoffeeLiquid`: тонкую сетку без коллизии и материал `/Game/Gameplay/Liquid/MI_CoffeePuddle`.

## Внешний вид

- Неровный контур, отдельные капли, закруглённый влажный край.
- Положение пятна задаёт стабильный вариант поворота и края; значение передаётся клиентам.
- Вершины привязаны к треугольникам языка и следуют его движению и прогибам. Трассировка нужна при создании; при обновлении используются сохранённые координаты внутри треугольников.
- Надписи `BRUSH 2` скрыты по умолчанию. Для отладки можно включить `Show Care Label` у пятна. Подсказки язв сохранены.

В экземпляре материала доступны `LiquidColor`, `EdgeColor`, `Roughness`, `Specular`, `Depth`, `Rim` и `WetSheen`. Последний управляет стилизованным отражением двух источников света: блик зависит от камеры и нормалей поверхности, чтобы жидкость читалась внутри закрытого рта. Параметры `WipeMask`, `Seed`, `WorldSize`, `Finish`, `Brush`, `BrushAge` заполняет код.

## Размер и контекст

Сервер выбирает размер из трёх групп: 30% маленьких, 40% средних и 30% больших. По умолчанию половина ширины сетки лежит в диапазоне 28–220 см; видимый неровный контур занимает часть сетки. Диапазон настраивается в `Liquid Size Range`, автоматический выбор отключается через `Randomize Liquid Size`. Позиции пятен получают небольшой разброс при появлении.

Цвет задаётся контекстом через `Liquid Material`: `MI_CoffeePuddle` для кофе, `MI_CurryPuddle` для карри и `MI_FoodSaucePuddle` как пример красного пищевого соуса. Это пресеты одного материала; для другой еды можно создать свой экземпляр. Случайное отклонение яркости ограничено 6% и не меняет основной цвет типа загрязнения.

Контекст можно назначить перед отложенным спавном или сменить на сервере вызовом `SetLiquidAppearance`. Новый пресет передаётся клиентам, а уже протёртая маска сохраняется. Система не создаёт проливы от всех блюд автоматически: событие еды выбирает нужный пресет, когда создаёт пятно.

## Чистка

Сервер сначала проверяет инструмент, расстояние, направление, препятствия и состояние игрока. Затем след щётки записывается в постоянную маску 64 × 64. Перемещение персонажа перемещает след; удержание щётки добавляет движение щетины поперёк пятна.

Материал показывает очищенный участок, валик перед щетиной и затухающую рябь. Это визуальная имитация: жидкость не участвует в Chaos и не рассчитывает сохранение объёма.

Игровые контакты остаются прежними: обучение требует два контакта, обычный кофе — четыре, по времени из `DA_ToothCare`. После последнего контакта остаточная плёнка уходит за 0,45 секунды. Поэтому для завершения задачи не нужно вручную проходить каждую отдельную каплю.

Маска передаётся сервером вместе с положением последней щётки. Поздно подключившийся игрок получает уже протёртые участки. Клиенты создают маленькую текстуру локально; текстуры рендера по сети не передаются. Повторный `ApplyCoffee` восстанавливает маску.

## Пересборка материала

При запущенном редакторе, остановленном Play-In-Editor и встроенном MCP Epic на порту 8000, из корня проекта:

```powershell
python Tools/Unreal/create_coffee_puddle_mcp.py
```

Скрипт вызывает официальные `MaterialTools`, `ObjectTools`, `MaterialInstanceTools` и `AssetTools`. Дополнительный сервер Unreal не устанавливается. Значения, переопределённые художником в `MI_CoffeePuddle`, сохраняются.

`create_coffee_puddle.py` также поддерживает запуск внутри Python Unreal. Карта, материал кофейного потока, налёт на зубах и материал язв этим генератором не меняются.

## Проверки

`MessControl.Liquid.PersistentLocalWipe` проверяет локальность следа, сохранение прежней очистки, некорректные входы и ограничение большого шага времени.

`MessControl.Liquid.AuthoritativeBrushContact` проверяет реальный путь контакта персонажа, выход из радиуса, повторное загрязнение, совместную чистку, отсутствие щётки и защиту язв.

`Tools/TestCoffeePuddles.ps1 -Capture` запускает хост и трёх клиентов. Все чистят настоящими щётками. Проверяются получение маски, завершение задач и совпадение контрольных сумм масок, размеров, вариантов формы и пресетов кофе/карри/соуса на всех четырёх процессах. Кадры сохраняются в `Saved/PuddleFrames`.
