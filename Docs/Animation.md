# Animation Lab

F1 открывает UMG-виджет с живыми настройками. В `DA_ToothAnimation` лежат общие значения. Ползунки меняют только локальный визуальный профиль, а не коллизии, скорость работы или сетевую физику.

`Save local preset` сохраняет `Saved/AnimationTuning.ini`. Для переноса в общий Data Asset остановить PIE и выполнить **Tools → Execute Python Script → Tools/Unreal/apply_animation_preset.py**. Затем закоммитить `DA_ToothAnimation.uasset`. `Reset from Data Asset` сбрасывает локальные настройки к общему профилю.

| Принцип | Реализация прототипа / точка развития |
|---|---|
| Squash and stretch | `BodyPivot`: сжатие при беге, приземлении и замахе; растяжение в воздухе; XY компенсирует объём. |
| Anticipation | Короткий наклон и сжатие перед работой щёткой; время настраивается. Прыжок пока срабатывает сразу ради отзывчивости. |
| Staging | Постоянный ракурс камеры, крупные силуэты и подписи LMB/E над заданиями. |
| Straight ahead / pose to pose | Процедурные фазы покоя, движения, воздуха и работы. Для авторских pose-to-pose клипов предусмотрено расширение Blueprint; готового skeletal AnimBP пока нет. |
| Follow through / overlapping | Щётка запаздывает за сменой действия; её движение отличается по фазе от корпуса. |
| Slow in / slow out | Плавное затухание приземления, повороты CharacterMovement и интерполяция щётки. |
| Arcs | Дуга движения щётки вокруг `BrushPivot`, волнообразное покачивание корпуса. |
| Secondary action | Дыхание в покое, боковая качка во время бега, дрожание при вытягивании. |
| Timing | Tempo, скорость цикла, время замаха и длительность работы из DA событий. |
| Exaggeration | Общая сила визуальных акцентов с ограничением масштаба. |
| Solid drawing / posing | Читаемый объём моляра, парные корни, мягкие формы, устойчивый центр персонажа. Для 3D это руководство по силуэту, а не отдельный алгоритм. |
| Appeal | Кремовая эмаль, мятный пояс, маленькая щётка, лицо и мягкие пропорции. |

Не все 12 принципов являются параметрами. Часть относится к постановке и художественным решениям. Основа — процедурная анимация статических мешей; полноценный скелет, IK, ragdoll и авторские клипы — следующий этап.

Исходники: `ArtSource/MessControl.blend`, сцены `AssetWorkshop` и `Mouth_Preview`. Генератор `Tools/Blender/create_assets.py` воспроизводит исходный набор; он не сохраняет ручные изменения в существующем .blend, поэтому запускать его для регенерации осознанно.
