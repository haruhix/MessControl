# Tooth Lab

Новый игрок использует риг `SM_Teeth_rig` коллеги: свои кости, физические тела и процедурные позы. Squash/stretch добавлены в материал, так как морфов в этом риге нет. Настройки и ограничения: [PlayerAppearance.md](PlayerAppearance.md).

F1 открывает UMG-виджет с живыми настройками. В `DA_ToothAnimation` лежат общие значения. Верхние ползунки меняют локальный визуальный профиль. Нижняя секция Physics доступна хосту и меняет игровую физику; см. [Physics.md](Physics.md).

`Save local preset` сохраняет `Saved/AnimationTuning.ini`. Для переноса в общий Data Asset остановить PIE и выполнить **Tools → Execute Python Script → Tools/Unreal/apply_animation_preset.py**. Затем закоммитить `DA_ToothAnimation.uasset`. `Reset from Data Asset` сбрасывает локальные настройки к общему профилю.

| Принцип | Реализация прототипа / точка развития |
|---|---|
| Squash and stretch | Morph targets `Squash` / `Stretch`: сжатие при беге, приземлении и работе; растяжение в воздухе; формы компенсируют объём по XY. Коллизии не масштабируются. |
| Anticipation | Короткий наклон и сжатие перед работой щёткой; время настраивается. Прыжок пока срабатывает сразу ради отзывчивости. |
| Staging | Постоянный ракурс камеры, крупные силуэты и подписи LMB/E над заданиями. |
| Straight ahead / pose to pose | Процедурные скелетные позы и физическая симуляция падения. Подъём смешивает захваченную физическую позу со стойкой. Авторские клипы пока не добавлены. |
| Follow through / overlapping | Сдвиги фаз рук и ног, запаздывание щётки, физические пружины конечностей. |
| Slow in / slow out | Плавное затухание приземления, повороты CharacterMovement и интерполяция щётки. |
| Arcs | Дуга движения щётки вокруг `BrushPivot`, волнообразное покачивание корпуса. |
| Secondary action | Дыхание в покое, боковая качка во время бега, дрожание при вытягивании. |
| Timing | Tempo, скорость цикла, время замаха и длительность работы из DA событий. |
| Exaggeration | Общая сила визуальных акцентов с ограничением масштаба. |
| Solid drawing / posing | Читаемый объём моляра, парные корни, мягкие формы, устойчивый центр персонажа. Для 3D это руководство по силуэту, а не отдельный алгоритм. |
| Appeal | Кремовая эмаль, мятный пояс, маленькая щётка, лицо и мягкие пропорции. |

Не все 12 принципов являются параметрами. Часть относится к постановке и художественным решениям. Текущая основа — процедурный скелет, физические конечности и ragdoll. Control Rig-граф, IK и авторские клипы пока не добавлены.

Исходники: `ArtSource/MessControl.blend`, сцены `AssetWorkshop` и `Mouth_Preview`; отдельный `ArtSource/ToothRig.blend` со скелетом. Генераторы `Tools/Blender/create_assets.py` и `create_tooth_rig.py` воспроизводят набор и перезаписывают собственные выходные файлы. Сохраняйте ручные правки отдельно.
