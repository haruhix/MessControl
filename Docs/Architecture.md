# Системы прототипа

`AMCGameMode` исполняется на сервере: выбирает случайное событие без немедленного повтора, создаёт задания, переключает дни, начисляет урон за пропущенные задачи и завершает забег после семи дней. `?Seed=123` фиксирует последовательность для воспроизводимых проверок. Сложность растёт по дням и числу подключённых игроков на момент начала дня.

`AMCGameState` реплицирует день, фазу, здоровье рта, количество заданий, текущий DA события, seed и серверное время завершения. HUD вычисляет таймер относительно синхронизированного `GetServerWorldTimeSeconds`.

`AMCToothCharacter` использует стандартное сетевое движение CharacterMovement и Enhanced Input. Клиент отправляет только начало/конец действия через RPC принадлежащего ему персонажа. Сервер самостоятельно выбирает ближайшую подходящую цель, проверяет дистанцию, высоту, направление и видимость. Клиент не передаёт произвольную величину прогресса. Несколько игроков ускоряют одну задачу сложением вклада.

`AMCTaskActor` реплицирует тип задачи и прогресс; завершение идемпотентно. Уменьшение налёта, подъём еды и выравнивание зуба отображаются на каждом клиенте. Задачи не являются физическими переносимыми предметами: вытягивание пока выражено накоплением прогресса и подъёмом модели.

`UMCPrototypeWidget` — нативный UMG HUD, F1 Animation Lab, F2 подключение. `UMCAnimationProfile` хранит параметры пластики, `UMCSoundPalette` — наборы звуков по именам событий, `UMCDayEvent` — настройки челленджа. Их можно редактировать без изменения C++.

## Карта

`L_Mouth`: отдельная визуальная поверхность языка, пять простых блокирующих объёмов, четыре PlayerStart, ряды зубов и свет. Декоративная геометрия отключена от collision. Игровой пол плоский на Z=30 см, задания появляются на Z=40 см. Камера направлена вдоль +X, движение W — вглубь рта. Дальнейшие декорации не должны пересекать маршруты к сетке заданий.

## Сеть

Listen server, максимум четыре игрока, подключение по IP. Нет Steam/EOS, поиска лобби, приглашений, NAT traversal, миграции хоста или reconnect/resume. Для внешней сети нужен доступный адрес хоста (UDP 7777) или VPN. Отключение хоста завершает сессию. Поздний вход получает актуальный GameState и существующие задания. Профили анимации локальны и не влияют на правила игры.

## Расширение

Создать новый `DA_MCDayEvent` и добавить в EventPool класса GameMode; новый тип механики потребует расширить enum и реализацию задания. Созданные `BP_ToothCharacter`, `BP_MouthTask`, `BP_MouthGameMode` — исходные точки для дизайнерских расширений. По умолчанию конфигурация использует нативные классы. Для собственного BP персонажа назначить его Default Pawn Class в BP GameMode и выбрать GameMode в World Settings.

Официальные справочные материалы: [GameMode / GameState](https://dev.epicgames.com/documentation/unreal-engine/game-mode-and-game-state-in-unreal-engine), [Data Assets](https://dev.epicgames.com/documentation/unreal-engine/data-assets-in-unreal-engine).
