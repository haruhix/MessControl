# Один день: первый игровой проход

Обычный `BP_MouthGameMode` запускает короткое обучение и последовательность:

1. Чистка зуба, нарезка и доставка еды, чистка языка.
2. Общая зубочистка в центре языка: волна боли при попадании, удержание E для извлечения, удар киркой, лечение язвы удержанием ЛКМ со спреем. Пульсирующая подсказка меняется вместе с действием.
3. За обучение команда получает первый уровень. Каждый выбирает один личный перк из трёх. Персонажи и выборы сохраняются при переходе.
4. Ореховый дождь: настоящая модель грецкого ореха и существующая параболическая подача еды. После последнего полёта самые поздние оставшиеся свободные орехи оживают и атакуют. Собранные и сданные орехи не превращаются.
5. После победы над орехами текущий адаптивный директор управляет коротким промежутком.
6. Существующий босс завершает этот первый вариант дня. Победа определяется его смертью.

Завершённая доставка, чистка, ремонт, лечение и разбивание льда дают общий XP. Каждый уровень создаёт независимую очередь личных предложений. Очередь и перки переживают замену персонажа; повторная отправка выбора не выдаёт награду второй раз. Легендарный инструмент из личного предложения принадлежит выбравшему игроку. Исходные сундуки сохраняют свою отдельную механику.

## Настройки для тестирования

- `/Game/Gameplay/CoreLoop/DA_NutRain`: базово 30 орехов за 12 секунд, 4 врага; дополнительные игроки увеличивают количество. Настройки содержат пределы, время ожидания последнего полёта, здоровье, скорость и урон врагов.
- `/Game/Gameplay/CoreLoop/DA_SingleDay`: варианты орехового события, 25 XP за победу над орехами, 30 секунд директора, класс финального босса. Один вариант выбирается воспроизводимо по seed; список позволяет менять наполнение первого этапа без смены его позиции.
- `AMCGameState.Progression`: первый порог 50 XP, прирост порога 25. Личные карточки используют реальные инструменты и три повторяемых восстановительных перка; пустые старые заглушки отключены для повышения уровня.

Это первый вариант с одним новым основным событием. Дополнительные события и сочетания A+Z/A+X/A+C ещё предстоит наполнить контентом и сбалансировать.

## Разработка и проверка

Авторинг: `Tools/Unreal/author_nut_rain.py`, затем `Tools/Unreal/author_single_day.py` после сборки Editor target. Скрипты сохраняют изменения через Unreal, проверяют отсутствие чужих несохранённых пакетов и сохраняют существующие настройки профилей. `isolate_walnut.py` выделяет отдельный целый орех, половинку скорлупы и ядро из исходной коллекции Fab, центрирует их и сохраняет UV и материал. Импортированные пакеты проверяются по хешам и не изменяются.

`-MCSingleDay` включает новую последовательность на нативном GameMode. `-MCLegacyDays`, `-MCCore` и `-MCDayOne` сохраняют прежние диагностические сценарии. Нативный GameMode по умолчанию сохраняет режим существующих тестовых fixtures; обычная сохранённая Blueprint включает новый день.

Фокусные Automation-фильтры: `MessControl.Progression`, `MessControl.SingleDay`, `MessControl.CoreLoop.NutRain`, `MessControl.Tutorial.Toothpick`. `-MCSingleDayTest` запускает сценарную проверку в сохранённой арене. Это программное прохождение, которое отдельно отмечает вызовы серверных действий и проверку настоящих взаимодействий; оно не заменяет балансировку людьми.

`Tools/Unreal/validate_single_day_network.py` создаёт собственную PIE-сессию с двумя игроками на listen server и затем восстанавливает настройки редактора. Он проверяет общий XP, приватную репликацию предложений, личные награды и продолжение дождя при новых выборах. Обучение в этой отдельной проверке пропускается через нативный переход. Выбор удалённого игрока вызывает существующий обработчик карточки на следующем тике мира: прямой Python-вызов RPC в редакторе UE выполнялся бы локально под `FEditorScriptExecutionGuard`.

Подтверждено: 18 Automation-тестов, 18 проверок сценарного прохождения сохранённой арены и 23 проверки двух сетевых игроков. В сценарном прохождении зубочистка и бой с орехами используют обычные входы персонажа; финальный босс получает программный серверный урон для проверки перехода к победе. Полный бой с боссом и количество орехов требуют игрового тестирования людьми.

Windows cook/package для этой переработки не запускается.
