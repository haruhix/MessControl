# Процедурный хват еды

Удерживать E возле еды. Персонаж подводит ладони к видимой поверхности, затем
начинает прикладывать силу. Во время хвата разворот сохраняется: можно пятиться,
идти боком и толкать перед собой. Отпустить E — руки плавно возвращаются к
обычному движению. Q использует существующий бросок.

## Как выбирается поза

| Положение предмета и движение | Реакция |
| --- | --- |
| Предмет впереди, игрок отступает | Тяга двумя руками |
| Предмет впереди, игрок идёт к нему | Толкание двумя руками |
| Предмет слева / справа | Ближняя рука |
| Предмет сзади | Тяга двумя руками за спиной |

Углы имеют запас переключения, чтобы руки не менялись каждый кадр на границе.
У повёрнутого края или маленького фрагмента может быть доступна только одна
рука: она начинает хват, вторая подключается, когда до неё можно дотянуться.
Новый хват подводится плавно. Ладони остаются в выбранных локальных точках
предмета при его движении и вращении; сила появляется только после контакта.
Корпус подаётся к предмету и наклоняется с учётом усилия. Длина костей
ограничена: при чрезмерном разрыве контакт отпускается.

Два игрока добавляют силу; масса предмета продолжает определять ускорение.
Застрявшую еду нужно тянуть в указанную сторону. Удержание не блокирует
ragdoll: удар освобождает предмет и возвращает физику обеих рук.

## Проверка в редакторе

1. Открыть L_Mouth, Play, F3 → «Руки — хват, тяга и толкание».
2. Подойти к появившемуся тестовому кубу вплотную и удерживать E.
3. Пятиться, затем двигаться вперёд. Отпустить, подойти боком или спиной и
   повторить: сменится количество участвующих рук.
4. Повторить с едой из завтрака и вдвоём. Проверить удар / ragdoll через F3.

Куб нужен для проверки контакта на хорошо различимой поверхности. Кнопка
удаляет только предыдущий предмет этой проверки. Обычная еда использует
тот же компонент; её видимые меши и физические габариты должны соответствовать.

## Настройки

`/Game/Data/DA_Grip` → Settings, менять при остановленном Play.

| Поле | Зачем |
| --- | --- |
| Reach Seconds / Release Seconds | Время подвода и отпускания ладоней |
| Body Reach | Подача корпуса к предмету в сантиметрах |
| Crouch Depth | Подача корпуса вниз к низким предметам |
| Max Arm Stretch | Небольшой допустимый запас длины, по умолчанию 1,08 |
| Contact Tolerance | Допуск между ладонью и контактом до включения силы |
| Break Slack | Запас перед разрывом хвата при сильном смещении |
| Palm Length / Thickness | Положение контактной точки относительно кисти |
| Front Angle / Rear Angle / Angle Hysteresis | Сектора двух рук и бокового хвата |
| Drive Force / Spring / Damping | Сила движения, натяжение и гашение колебаний |
| Lean | Наклон корпуса при усилии |

`DA_FoodPhysics` сохраняет массу, удары, предел поиска и правила извлечения.
Его прежние Spring / Damping больше не управляют тягой: используйте DA_Grip.

## Что создано и зачем

- `MCGripComponent` — проверка досягаемости и препятствий, репликация контактов,
  выбор позы, сила и решение цепочки плечо–локоть–кисть.
- `MCFoodActor.GripSurface` — невидимая копия для точного запроса поверхности
  меша. Она не добавляет физический вес или отдельный твёрдый коллайдер.
- `MCToothAnimInstance` — применяет решение рук поверх процедурной походки.
- `MCToothPhysicsComponent` — выключает свободное болтание только занятых рук,
  возвращает его после отпускания; ragdoll использует всё тело.
- `DA_Grip` — настройка без правки кода; существующий риг художника сохранён.

Сервер решает, кто действительно держит предмет, прикладывает силы и проверяет
разрыв. Клиенты получают точки и состояние хвата, строят позу локально.
Стандартный сильный автоматический толчок CharacterMovement отключён:
движение еды определяется физическим контактом и настроенной силой хвата.

Это процедурный контакт ладоней с жёстким мешем. Отдельный обхват каждого
пальца, мягкая деформация еды и специальные авторские анимации ещё не добавлены.
Для новой модели понадобятся корректные роли костей в DA_PlayerAppearance,
проверка длины рук и настройка ладони; неправильные веса IK не исправляет.

`Tools/Test.ps1 -Mode GripNetwork -PacketLagMs 75 -PacketLoss 2` проверяет
четыре направления хвата, перемещение еды, отпускание и ragdoll на четырёх
процессах. `-CaptureGrip` дополнительно сохраняет снимки и их время в Saved.

`Tools/CaptureGrip.ps1` запускает эту проверку и собирает `Artifacts/Grip.mp4`.
Качество рендера снижено только в процессе записи; настройки проекта не
сохраняются. Временные интервалы снимков сохранены, видео не является замером FPS.
