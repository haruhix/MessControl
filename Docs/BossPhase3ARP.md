# Босс третьей стадии: скелет Auto-Rig Pro

`BP_BossPhase3` использует исправленные веса и риг из
`C:/Users/vasil/Desktop/Animation/arp_weights/carries_weights_fixed.blend`.
Рабочая копия для добавления анимаций:
`ArtSource/BossPhase3ARP/BossPhase3ARP_Export.blend`.
Полный снимок открытой сцены до экспорта сохранён отдельно в
`BossPhase3ARP_Source.blend`; исходный файл на рабочем столе не перезаписывается.

Единственный скелет новых клипов:
`/Game/Gameplay/Boss/Phase3/Rig/SK_BossPhase3_ARP_Skeleton` (104 кости).
Модель: `SK_BossPhase3_ARP`. Профиль: `DA_BossPhase3`.
Компонент модели имеет масштаб 0.4802498816 и Yaw -90°, чтобы сохранить
рост около 300 см (+25%) и направление движения нативного босса. Объём
попаданий корпуса также увеличен на 25%, его нижняя точка остаётся на прежней
высоте. Навигационная капсула сохраняет исходные размеры. Вершины, UV,
исправленные веса и shape key `Open_Mouth` экспортируются из исходника.

| Назначение | Action в Blender | Клип в Unreal |
|---|---|---|
| Ходьба | `walk`, кадры 1–44, 30 fps | `AN_BossPhase3_ARP_Walk`, 1.433 с |
| Удар | `hit_atack_01`, кадры 37–84 | `AN_BossPhase3_ARP_Hit`, 1.567 с |
| Покой | начальная неподвижная поза `hit_atack_01` | `AN_BossPhase3_ARP_Idle` |

Удар занимает слот `PunchRight`. Начальная подготовка вырезана: воспроизведение
начинается с кадра 37, серверное попадание привязано к кадру 43 (0.2 с после
начала клипа), а не к animation notify. Перед началом клипа босс стоит в покое
0.50 с (`StartDelaySeconds`): попадание наступает примерно через 0.70 с после
выбора атаки. Дополнительный cooldown равен нулю, решения
AI проверяются каждые 0.1 с, радиус атаки — 280 см до поверхности капсулы игрока.
В контакте с капсулой корпуса угол удара не создаёт слепой зоны; дальше
сохраняются фронтальный конус, высота и проверка стен.
Root motion выключен: перемещение по NavMesh выполняет нативный AI.
Переходы между клипами смешиваются за 0.30 с (`AnimationBlendSeconds` в
профиле). После паузы удар начинается с полным весом, без смешивания на входе,
и проигрывается до последнего кадра. Переход к ходьбе или покою может
смешиваться только после завершения удара. Серверное попадание по-прежнему
происходит через 0.2 с после начала клипа. Переходы между ходьбой и покоем сохраняют смешивание;
следующие клипы в слотах атак автоматически используют ту же защиту.
Все восемь прежних `AN_BossPhase3_*` удалены из Content. До удаления проверены
сохранённые ссылки; резервные пакеты лежат в `Artifacts/BossPhase3ARP/Before`.
Пустые hurt/death/roar и другие атаки очищены в профиле.

F3 → «Босс · фаза 3» → «создать для просмотра» создаёт босса в покое.
Кнопки «Ходьба» и «Удар правой рукой» показывают новые клипы. «Восстановить
и включить AI» включает бой. Остальные прежние кнопки панели пока не имеют
клипов и сообщают, что анимация не назначена; старые клипы не подставляются.

## Добавление следующей анимации

1. Откройте рабочую `.blend`-копию и создайте новый Action на `rig`.
   Имена костей, иерархия и rest pose должны сохраняться.
2. Добавьте запись в `ArtSource/BossPhase3ARP/clips.json`: `name`, `action`,
   `start`, `end`, `role`. Для атаки также нужны `attack_id` и `impact_frame`.
   Поддерживаемые роли: `idle`, `walk`, `hurt`, `death`, `roar`, `attack`.
   Для атак можно задать `damage`, `range`, `half_angle_degrees`, `weight`,
   `cooldown`, `start_delay_seconds`. Идентификаторы атак должны быть уникальными.
3. Запустите Blender с `Tools/Blender/export_boss_phase3_arp.py`.
   По умолчанию читается рабочая копия; альтернативный файл можно передать
   после `--` параметром `--source путь/к/файлу.blend`.
4. В Unreal выполните `Tools/Unreal/import_boss_phase3_arp.py`, затем
   `Tools/Unreal/connect_boss_phase3_arp.py`. Для подключения остановите PIE.

Повторный импорт загружает существующий mesh/skeleton и импортирует только
анимации. `RigContract.json` проверяет rest pose исходного рига, настройки
экспорта, имена и родителей костей. Смена рига требует отдельной миграции;
повторный импорт не пересоздаёт скелет и не обновляет reference pose.
Кнопки F3 для атак используют существующие имена `PunchLeft`, `PunchRight`,
`Kick`; произвольные уникальные идентификаторы работают через профиль AI.

Модель и анимации экспортируются отдельно, ограничения ARP запекаются в
bone tracks. Настройки соответствуют [официальной документации Auto-Rig Pro](https://www.lucky3d.fr/auto-rig-pro/doc/ge_export_doc.html).
