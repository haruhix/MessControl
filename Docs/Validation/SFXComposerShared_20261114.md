# Отдельный SFX Composer и общий аудиочерновик — 2026-11-14

## Изменения

- Добавлено отдельное окно `Tools → SFX Composer`: дерево владелец → действие → событие, контекстное превью, звуковые слои, музыка/атмосфера и нижняя библиотека. VFX сохраняет свой текущий интерфейс; новый SFX не открывает старую VFX-оболочку как зависимость.
- Оба окна получают один action document по стабильному ActionID. Аудиослои, GUID, параметры и Undo/Redo общие. Навигация независима; явная кнопка «Открыть VFX» выбирает соответствующее событие/слой.
- Preview принадлежит конкретному окну и эпохе запуска. Чужие навигация, Stop, Pause и закрытие окна не останавливают нового владельца. Сохранение звука переносит только аудиоданные и сохраняет неприменённый визуальный черновик. Известное сохранение соседнего действия в том же owner безопасно обновляет baseline других открытых документов.
- Библиотека обнаруживает импортированные `/Game` SoundBase через Asset Registry, имеет проводник папок, поиск, сортировку, длительность, предпрослушку и настоящую волну импортированного WAV. PCM декодируется при явном Play, а не при просмотре пачки. Для Cue/MetaSound и неподдерживаемого PCM показывается честный переход в редактор источника.
- После замечания пользователя DnD получил постоянные пунктирные цели: вся область слоёв добавляет новый слой, строка заменяет источник конкретного GUID. Над библиотекой есть отдельные Add/Replace цели, включая развёрнутый режим. Hover валидирует метаданные без загрузки источника, показывает назначение и подсветку; смена цели/токена отклоняется, отказ Replace не превращается в Add через bubbling. Есть кнопка «Добавить выбранный звук».

## Проверено

- `MessControlEditor Win64 Development`, UE 5.8.1: PASS. Последняя сборка после DnD исправлений: 24.67 с. Первые ошибки компиляции устранены до успешных сборок; cook/package не выполнялись.
- Четыре направленных Automation-теста `MessControl.Composer.Shared.*`: PASS, без warnings/errors. Проверены общий документ, независимая навигация, Undo/Redo, audio-only сохранение при визуальном черновике, сохранение sibling owner и preview lease при одинаковом/разном действии. Использованы изолированные fixture mounts под `Saved/Checks`, реальные game source assets не перезаписывались. Первая попытка была отклонена защитой активного preview; после его остановки все четыре прошли. Старый `MechanicOnlyProviderCanPlay` также прошёл после актуализации ожидания: Initialize теперь только открывает документ.
- Реальная UI-проверка на `Active_Hook / Start`: кнопка библиотеки добавила один S_Hit; DnD в Replace заменил источник на cut с сохранением GUID и количества слоёв; DnD в общую область добавил второй слой. Снимки SFX/VFX содержат одинаковые audio_layers и draft_token.
- Изменение enabled в SFX отобразилось в VFX; обратное изменение в VFX отобразилось в SFX. Ctrl+Z и Ctrl+Y обновили оба окна. QA-правки затем поштучно отменены до чистого baseline; игровые аудиопрофили не сохранялись, dirty packages нет.
- `S_Hit`: предпрослушка построила 512 min/max buckets реального импортированного PCM; отображалась длительность 0.18 с. Физическая слышимость/качество микса отдельно не оценивались.
- Лично просмотрены нативные окна 1920×1080, 1536×960 и развёрнутая библиотека. Обе цели DnD видимы; поиск/выбор сохраняются при раскрытии. В компактном dock помещается примерно одна строка: для пачек нужен развёрнутый режим. Независимый дизайнер также проверил эти три снимка. Hover визуально отдельно не зафиксирован: переносы проверены функционально, код подсветки проверен отдельно.
- Настоящий Hook sandbox с включённым preview audio завершил Start, LoopStart, Impact, LoopStop, End, ActionFinished. Осмотрен реальный viewport и тайминг событий. Это isolated preview, не PIE и не художественное принятие анимации. В общей sandbox диагностике остался посторонний `Food.AutoMouth` preload warning; полная готовность ресурсов локации не заявляется.
- `UIResults.json`: 13/13 проверок сохранённых UI-снимков PASS. Начальная проверка использовала `selected_layer` VFX, который обозначает только VFX-слой; проверка исправлена на доступные поля события/аудиоинспектора. Точный аудиослой подтверждён живым инспектором и двусторонней правкой второго GUID.

## Границы этапа

Случайные группы вариантов, Ready/Lock, постоянный каталог внешних файлов без импорта, полная адаптация каждого игрового события и дальнейшая переработка VFX UI остаются последующими этапами. Sound Cue/MetaSound можно открыть в настоящих редакторах схем. «Примерить в действии» временно добавляет звук; адресная замена при примерке ещё не реализована.

Библиотека работает с импортированными Unreal-ассетами. Настройки AlwaysCook не изменены, поэтому неиспользуемый импортированный звук не обещается исключённым из билда. Новые UI brushes только editor Slate; новых runtime visual resources для preload manifest нет. Сохранённые игровые пакеты этим этапом не менялись.

Остались небольшие UI-ограничения: после полного Undo нижний status может сохранять сообщение «Изменён черновик», хотя dirty=false, заголовок чистый и Save выключен. В логах Slate есть font fallback warnings для локализованного пробела U+202F и символа дубликата U+29C9; tooltip операции доступен. Это не исправлялось в завершающей проверке DnD.
