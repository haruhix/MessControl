# Нарезка → крошки → глотка, 2026-11-08

Новый режим включён через `DA_FoodPhysics.Settings.bAutoConsumeSmallCuts`.
Выключение возвращает сохранённые сбор/стопку/ручную подачу. Порог порции
сохранён: `MaxHandDimensions=110 cm` по каждой оси. Крупные части дорезаются,
готовые завершаются ножом; массовый бюджет и существующий одноразовый зачёт
сохраняются. Испорченное/мусор/перец и ореховые боеприпасы сохраняют свои правила.
Отсутствие глотки или поддерживаемых исходных фрагментов не удаляет продукт.

`Food.AutoMouth / Consume` использует сохранённый editable Niagara-профиль и
стабильный источник GameState. Частицы не являются сетевыми физическими телами.
Два CPU-эмиттера дают до 16 mesh-крошек и 10 мягких пылинок на порцию. Девять
цветов заданы в строках меню; профиль достижим через arena `DA_MouthPresentation`.
Шесть подсказок обучения добавлены на десяти языках с prewarm. Сетевая версия
повышена до 2 из-за новых полей реплицируемых настроек/строк еды.

слишком широкое кадрирование для художественной приёмки. В solo отмечен один
поздний Editor shader у существующего `MM_StylizedVegetables`; чистый packaged

естественное завершение и очистку (0 active/0 running players); в свежем диапазоне
лога предупреждения Asleep нет. Фоновое ограничение Editor на время проверки
отключалось и восстановлено. Эта смена политики не меняла artwork/траекторию
в предшествующей solo-записи.
