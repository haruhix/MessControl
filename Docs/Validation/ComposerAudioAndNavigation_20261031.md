# Composer: категории и первый SFX-этап

Проверено root 31.10.2026 UTC / 01.11.2026 по Якутску. UE 5.8.1, проект `E:/DEVGAME/MessControl`. Новые изменения этого блока не закоммичены.

## Результат

- Общий список действий имеет категории и Unicode-поиск RU/EN/ID. Бустеры фильтруются по фактическому Kind. Смена фильтра не меняет идентичность/слои/dirty/playback черновика; это проверено ранее через настоящий Slate и повторено native-тестами.
- Добавлены независимые SFX-слоты и экземпляры звуков в тех же событиях, их параметры/Undo/дублирование, подготовка ресурсов и ограниченный lifecycle. VFX и игровой результат не зависят от успешности аудио. Статические Wave/Cue подготовляются перед запуском; динамические графы без доказанной зависимости отклоняются явно.
- Generic presentation и активки используют существующие принятые события/transport. Реальные Start/Loop/Impact/End активок не заменяются универсальной выдуманной временной шкалой. Отмена/reset прекращают собственный звук; допустимый конечный хвост принадлежит миру.
- Песочница использует отдельное явно включаемое аудиоустройство. Исправлен реальный editor pause gate: только приватные SFX-компоненты получают локальное исключение; их Pause применяется явно. Родные SoundBase и другие миры не меняются.
- Save/reopen проверен на изолированном canonical owner. Настоящая Mouth-библиотека не записывалась. Неизвестная группа в том числе выключенного VFX-слоя отклоняется до сохранения/превью.

## Остаётся

Интерактивные группы в графе, SavePack/LoadPack/A-B UI, отдельные original-SFX hooks и перенос всей игры ещё не завершены. Замена/отключение родного звука пока заблокированы без конкретного доказанного триггера. Read-only source-аудит пяти активок и двух ореховых ролей не нашёл отдельного native SFX в этих class scopes; это не аудит Niagara/Blueprint/animation-audio всего проекта.

Не выполнялись сеть, микрофон, cook/package, холодный packaged-запуск и новая художественная приёмка эффектов. Прогрев подтверждает зависимости/Precache/стартовые сжатые данные, не декодированный первый буфер или отсутствие DSP-стоимости. MP4/GIF и интерактивная доска отложены по указанию пользователя; короткий WAV служит только локальным доказательством выхода.

Согласованный процесс паков и разделение группы/версии: [VFXComposerPacksAndNavigation](../VFXComposerPacksAndNavigation.md).
