# Перенос на события и общий UX Composer — 2026-11-14

## Изменения

- SFX принимает звук прямо на конкретное событие в левом дереве, включая событие другого действия. Append использует общий документ цели; предварительный выбор действия/события не требуется. Текущие выделения обоих окон сохраняются, число звуковых слоёв показывается у события. Папки, владельцы и заголовки действий не выбирают событие за пользователя.
- VFX получил дерево раздел → владелец → действие → реальные события вместо плоских больших карточек. Источник — прежний общий каталог, отдельного инвентаря действий нет. Дерево принимает звуки и Niagara как новые независимые слои конкретного события. Контекстный граф и редакторы слоёв сохранены.
- Компактные Play/Pause/Stop, Repeat, audio и scenario находятся под viewport VFX. В режиме одной схемы есть компактный нижний transport. Контраст текста Play исправлен по реальному скрину. Звуковая библиотека VFX теперь использует тот же `SMCSFXLibrary`, что и SFX: папки, поиск, waveform и длительность.
- В каждой строке библиотеки постоянно видна кнопка ▶. Она выбирает и слушает конкретный файл; при своём активном проигрывании становится ■. Нижняя кнопка называется «Слушать звук». Прослушивание отдельно от Add/Apply/примерки; drag остаётся доступен на остальной строке. Повторный выбор того же файла сохраняет waveform/seek.
- Hover использует Asset Registry и read-only `MCComposerDocuments::Find`, без Acquire, source load, выбора действия и preview claim. Drop проверяет точные ActionID/Event/token, исходный документ и canonical baseline до/после явной загрузки источника. Общий asset drag contract сохраняет origin между SFX/VFX; библиотека доступна для drag и из контекста без редактирования текущего события. Добавлен read-only снимок всех открытых документов для проверки скрытых черновиков.
- Fallback-категории реакций известных владельцев приводятся к разделу их семейства. Реакция `Boss.NutKnight.Hurt` раньше создавала второго «Рыцаря» в «Другое»; теперь она находится в общей папке босса. Исходные SourceOwner, ActionID и capabilities не менялись.
- Сообщение после Undo/Redo теперь отражает восстановление сохранённых данных и не приписывает правку постороннему документу.
