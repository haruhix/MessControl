## Статичный просмотр первого запуска · UX Build01

Независимый агент лично осмотрел `E:/CodexWork/MessControl/Validation/ComposerUX_20261031/FirstLaunchUI.png` и соответствующий `.txt`. Первый следующий шаг уже понятен: библиотека открыта, карточки подписаны «Клик — посмотреть», справа есть шаги 1–2–3, состав равен нулю. Первоначальная претензия к полностью пустому графу этим кадром не повторяется.

1. **Подтверждённый blocker:** активные mint controls («Библиотека», «Выбрать эффект», Add) имеют слишком низкий контраст и выглядят disabled. UI-агент уже исправляет только контраст; новая функциональность для этого не нужна.
2. **Узкий риск, ещё не доказанный как runtime-дефект:** top «+ Добавить эффект», right «Выбрать эффект» и bottom Add могут восприниматься одинаковыми действиями. Следующий selection-кадр должен явно показать audition и одну основную команду «Добавить [имя] в композицию», со счётчиком 0 до Add. По одному начальному кадру нельзя объявить этот маршрут сломанным.

Одинаковые изображения карточек — текущие реальные thumbnail ресурсов, отдельный вопрос будущей курации библиотеки; подменять их выдуманными картинками не предлагается. Статичный screenshot сам по себе не засчитывается за нажатия, сохранение или экспорт. Позднейший native-проход Build02 отмечен ниже отдельно.
